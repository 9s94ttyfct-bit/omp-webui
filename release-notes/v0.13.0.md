## English

### Agents can look up how omp-webui works

- The agents in your conversations now have a read-only tool, `webui_docs`, that answers questions about omp-webui itself from its own documentation: what a feature does, where it is in the app, every setting with its key, allowed values, default and effect, the server's API routes and which of them only work on the computer omp-webui runs on, limits and security notes. Ask the agent "how do I let my phone reach this Mac?" or "what does *Where a compact you queue runs* do?" and it reads the answer instead of guessing.
- The tool lists the topics, searches them by keywords and reads a topic or one section of it. It opens no file, changes no setting, runs nothing and sends nothing anywhere: the documentation is built into the app, and a name that is not a topic (a path) is refused. No permission mode asks about it. It costs a conversation that never uses it one line of its prompt: omp mounts it at `xd://webui_docs` and shows its full description only when the agent asks.
- Every conversation the app starts has it, except one started with your own `--trusted-extension` flag (omp does not allow the app's extensions next to it). A conversation started before the update has it from its next start.
- The documentation is `docs/agents/` in the repository, one page per feature area, with an index and an `llms.txt` at the root. It is in English only, by choice; the agent answers you in your language. A test holds it to the code: a setting, a Settings entry or an API route that the app has and the documentation does not (or the other way round) fails the checks every change must pass.

## 中文

### 智能体可以查阅 omp-webui 的用法

- 对话里的智能体现在多了一个只读工具 `webui_docs`，用 omp-webui 自己的文档回答关于 omp-webui 本身的问题：某个功能做什么、在应用的哪里、每个设置的键、允许的取值、默认值和作用、服务器的 API 路由以及哪些只能在运行 omp-webui 的这台电脑上使用、限制和安全说明。问智能体“怎样让手机连到这台 Mac？”或“‘你排队的压缩在何时执行’是做什么的？”，它会去读答案，而不是猜。
- 这个工具可以列出主题、按关键词搜索、读取一个主题或其中的一节。它不打开任何文件、不改任何设置、不运行任何东西，也不向任何地方发送内容：文档内置在应用里，不是主题名的名字（比如路径）会被拒绝。任何权限模式都不会为它询问。不用它的对话只为它多付提示词里的一行：omp 把它挂在 `xd://webui_docs`，智能体需要时才显示完整说明。
- 应用启动的每个对话都有它，只有用你自己的 `--trusted-extension` 参数启动的对话除外（omp 不允许应用的扩展和它同用）。更新之前就已启动的对话，在下次启动时带上它。
- 文档在仓库的 `docs/agents/` 里，每个功能领域一页，另有索引和根目录的 `llms.txt`。文档有意只用英文；智能体会用你的语言回答你。有一个测试让文档和代码保持一致：应用里有而文档没写的设置、设置页条目或 API 路由（或者反过来），都会让每次改动必须通过的检查失败。
