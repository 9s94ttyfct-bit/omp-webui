## English

### Delete a conversation together with what it left on disk

- **The delete dialog can move the conversation's folder to the Trash too.** Under the conversation it offers **Also move its folder to the Trash**, or **Or only its dependency folders**: `node_modules`, a virtualenv (`.venv`, `venv`), Rust's `target`, CocoaPods' `Pods`, and Gradle's `build`/`.gradle` or Go's and PHP's `vendor` when git ignores them. Each one shows its full path and size; nothing is ticked until you tick it. Ticking the folder takes its dependency folders with it.
- **Bulk delete too.** Each selected conversation with something to offer is a row of its own (**N can go to the Trash**); open it to tick what goes. Above the Delete button a line says how many items will go to the Trash.
- **Only after the delete, and only into the Trash.** omp deletes the conversation first; then what you ticked is moved to the Trash (Finder's **Put Back** restores it). What could not be moved is named in a message, and the conversation stays deleted.
- **Checked again when you confirm.** Your home folder and anything above it, system folders, and omp's and omp-webui's own data are never offered. A folder another conversation, a sidebar project, a Terminal tab or a running process works in is not moved, and the dialog says who; a dependency folder is held back only by what runs in the folder now. A folder with uncommitted changes or commits not pushed says so, and is not moved if git has more there than the dialog showed. A git worktree is marked: git lists it until `git worktree prune`.
- On a Mac only (it uses `/usr/bin/trash`). On a Linux or Windows server the delete dialog is as before.

## 中文

### 删除对话时，一并清理它留在磁盘上的东西

- **删除确认框可以把对话的文件夹一起移到废纸篓。** 对话下方提供 **同时把它的文件夹移到废纸篓**，或者 **只移走依赖目录**：`node_modules`、虚拟环境（`.venv`、`venv`）、Rust 的 `target`、CocoaPods 的 `Pods`，以及被 git 忽略时的 Gradle `build`/`.gradle`、Go 和 PHP 的 `vendor`。每一项都显示完整路径和大小，默认都不勾选。勾选文件夹时，它里面的依赖目录会一起移走。
- **批量删除也可以。** 每个有可清理内容的对话单独一行（**N 项可以移到废纸篓**），展开后勾选要移走的内容。删除按钮上方会写明删除后会把几项移到废纸篓。
- **先删除，再移到废纸篓。** omp 先删除对话，之后才把勾选的内容移到废纸篓（在访达里可以“放回原处”）。没能移走的会在提示里列出，对话仍然算已删除。
- **确认时会重新检查。** 主目录及其上级、系统文件夹、omp 和 omp-webui 自己的数据永远不会出现在选项里。其他对话、侧栏项目、终端标签页或正在运行的进程在用的文件夹不会被移走，确认框会写明是谁在用；依赖目录只会被此刻在那个文件夹里运行的东西挡住。有未提交改动或未推送提交的文件夹会标出来，如果确认时 git 里的改动比确认框显示的多，就不移动。git worktree 会单独标出：在 `git worktree prune` 之前，git 仍会列出它。
- 只在 Mac 上提供（用的是 `/usr/bin/trash`）。在 Linux 或 Windows 服务器上，删除确认框和以前一样。
