## English

### Downloads in the built-in browser

- **Downloading a file in the Browser tab works in the Mac app.** Clicking a download link used to do nothing. The file is now saved to your Mac's Downloads folder, with no dialog. If a file with that name is already there, the new one is called `name (1).ext`, `name (2).ext`, and so on. Like Safari, the app marks it as downloaded from the web. A new tab that a link opened only to download a file closes once the download is done.
- **The Browser tab lists the conversation's downloads.** Once a page of the conversation downloads something, a **Downloads** button appears in the tab's toolbar, with the number still running. Its list shows each download's name, progress and size, with **Cancel** while it runs. A finished one has **Show in Finder** on the Mac, and **Download to this device** on a phone or any other device signed in to this Mac (under the **File transfer** setting in Settings › Remote access, like a download from the Files tab). A toast says when a download starts, finishes or fails. The list is kept until the app quits.
- A file an agent downloads still goes to the folder the agent asked for, and is listed too.

## 中文

### 内置浏览器的下载

- **在 Mac 应用里，浏览器标签页可以下载文件了。** 以前点下载链接没有任何反应。现在文件不弹对话框，直接保存到 Mac 的“下载”文件夹；那里已经有同名文件时，新文件叫 `名字 (1).扩展名`、`名字 (2).扩展名`，依此类推。应用会像 Safari 一样把它标记为从网上下载的文件。链接只为下载而打开的新标签页，会在下载完成后自动关闭。
- **浏览器标签页会列出这个对话的下载。** 这个对话的页面下载过东西之后，标签页的工具栏里会出现**下载**按钮，上面显示还在进行的个数。列表里有每个下载的名字、进度和大小，进行中的可以**取消**。下载完成的，在 Mac 上可以**在访达中显示**；在手机或其他登录到这台 Mac 的设备上可以**下载到这台设备**（和文件标签页的下载一样，受设置 › 远程访问里的**文件传输**控制）。下载开始、完成或失败时会有提示。列表保留到应用退出为止。
- 智能体下载的文件仍然保存到它指定的文件夹，也会列出来。
