这一版主要改进界面设计、手机与平板上的布局，以及无障碍体验。

## 布局与操作

- **右侧面板**：手机和平板上改为带遮罩的抽屉，点遮罩或按 Esc 都能关闭；关闭按钮在任何宽度下都在屏幕内，标签页保持一行（手机上未选中的标签只显示图标）。在其他对话之间切换时，手机上的面板会自动关闭。
- **对话页顶栏**：窄屏下优先保留标题，会话设置、费用、上下文用量、重命名、导出和目标收进“⋯”菜单；额度标记不再换行；标题和过长的路径以“…”结尾，悬停可看完整内容。
- **提示**：移到右上角，不再挡住发送按钮；鼠标悬停或聚焦时暂停计时，关闭按钮更容易点中。
- **加载失败**：对话、侧边栏和命令帮助会显示失败原因和“重试”，不再一直转圈；对话加载完成前不显示费用、导出、目标和输入框。
- **命令与终端页**：手机上改为列表在上、内容在下，“运行”按钮完整可见；侧边栏开关不再遮住页面标题。
- **新对话**：默认使用最近的项目目录，不再落到用户主目录（~）。第一次使用时会显示“选择文件夹”，选好之前不会启动 omp，已输入的内容会保留。空侧边栏会给出上手提示。
- **模型选择器**：打开时停在当前模型上，按 Enter 不会再误切换；同名模型会显示各自的 ID。
- **折叠的代理回合**：如果有工具调用失败，折叠时也会用红色标出“N 个失败”。
- **账号**：已登录的提供商排在前面，按钮改为“管理”和“添加账号”；其余提供商收在“其他提供商 (N)”里；`omp login` 等命令按代码格式显示。
- **用量页**：空表格不再只显示表头；首次使用时显示一个带“开始对话”按钮的欢迎页。
- **快捷键提示**：Windows 和 Linux 上显示 Ctrl，不再写死 ⌘。

## 视觉与无障碍

- 焦点环不再在输入框里画出一个方框，也不会让圆形的发送按钮变方；输入框的焦点显示在整张输入卡片上，所有控件仍然有清晰的焦点提示（包括 Windows 高对比度模式）。
- Markdown 表格里的单词不再从中间断开；表格太宽时可以横向滚动。
- 对比度达到 WCAG AA：浅色主题的占位文字从 3.3:1 提高到 5.4:1；深色主题的危险按钮从 3.0:1 提高到 5.8:1；当前行和高亮行增加了强调色竖条，并标注 `aria-current`。
- iPhone：输入框在触屏上使用 16px 字号，聚焦时页面不再自动放大；界面会避开刘海和 Home 指示条。
- 手机上命令面板的标题不再被截成几个字；新对话输入框底部的按钮会自动换行，不再被发送按钮挡住。
- 中文界面不再夹杂英文的角色标签和思考等级名称；版本切换器“1 / 2”紧贴在消息气泡旁边。
