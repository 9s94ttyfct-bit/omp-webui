## English

### The isolated environment's switch is in the conversation's header

- **A running conversation's folder is switched to or from an isolated environment from the header.** The switch (the box icon) sits in the row of buttons at the top right, beside the guard's, instead of under *This session* › *Advanced*. It is the folder's, as New chat's is: a change applies to every conversation in that folder, and a conversation already running takes it when it restarts (*Restart to apply* beside the title restarts it). In a narrow window the switch is in the header's ⋯ menu. Where this computer offers no isolated environment, there is no switch.

## 中文

### 独立环境的开关移到了对话顶部

- **正在运行的对话，可以直接在顶部切换所在文件夹的独立环境。** 这个开关（盒子图标）放在右上角那排按钮里，挨着守护的开关，不再藏在“当前对话”›“高级”里面。它和新对话里的开关一样作用于整个文件夹：切换后，这个文件夹里的所有对话都会受影响；已经在运行的对话要重启后才生效（点标题旁的“重启后生效”即可重启）。窗口较窄时，开关在顶部的 ⋯ 菜单里。这台电脑不支持独立环境时，不显示这个开关。
