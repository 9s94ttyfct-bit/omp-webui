## English

### macOS installer (#190)

- The macOS app now ships as a `.dmg`: open it and drag omp-webui onto Applications. The app is still not notarized, so every release lists the one-time step to open it (the `xattr` command, or System Settings › Privacy & Security › Open Anyway).

### Bilingual README and release notes (#191)

- The README is now in English and Chinese, with screenshots of the real interface, install and usage steps, and troubleshooting.
- Release notes are written in both languages from now on.

## 中文

### macOS 安装包（#190）

- macOS 应用现在以 `.dmg` 安装包发布：打开后把 omp-webui 拖到“应用程序”即可。应用仍未经过公证，所以每次发布都会附上首次打开的步骤（`xattr` 命令，或“系统设置 › 隐私与安全性 › 仍要打开”）。

### 中英双语的 README 和发布说明（#191）

- README 现在有英文和中文两个版本，包含真实界面的截图、安装与使用说明，以及常见问题排查。
- 从这个版本起，发布说明同时提供英文和中文。
