## English

### Full and Light instead of Online and Offline

- **Full** is what Online was: omp as you set it up. **Light** loads only the tools, MCP servers and skills you choose in Settings, which leaves the context window for the work, and runs on **your own models** or, as Offline did, on a **local server** (oMLX, Ollama or LM Studio).
- The mode belongs to each conversation. New chat has a **Full / Light** chip beside the other pickers, and the next new chat starts in the mode you last chose there. *This session* switches an open conversation: its omp is restarted and the same conversation resumed in the other mode, at once when it is idle, or after the turn when it is working (it says so, and you can take it back).
- The header says **Light**, or **Light · local**, for a conversation in Light mode. The Online/Offline switch has left the sidebar, and Settings › Mode is now Settings › **Full / Light**, with *Light's models*: your models or a local server.
- Your settings carry over: Offline becomes Light on a local server, with the same server, address, model, tools, MCP servers and skills; Online becomes Full.

### Settings in five pages

- Settings is five pages instead of one long column: **Look & layout**, **Conversations & files**, **Models & accounts**, **Approvals & safety** and **App & system**, each with its own address (`#/settings/<page>`) and scroll. `#/settings` opens the page you last used. The search still finds a setting on any page and takes you there, and a link to a card (from a toast or the shortcut list) opens the right page.

### Right panel: tabs where you want them, and a terminal

- Drag a tab from one pane of the right panel to the other, or use its menu to move it; a tab is in one pane only, so moving it takes it out of the other. The layout is remembered as before.
- A **Terminal** tab: your login shell (`$SHELL -l`) in the conversation's folder, one per conversation. It keeps running while you switch tabs, panes or conversations, and shows what it printed meanwhile; it ends with Restart, when the page closes, or with `exit`. After Run in Background the app's window takes its shells back.
- Remote pages (through the tunnel) may open a terminal by default. Settings › Remote access › **Let remote pages open a shell** turns that off: the server refuses the shell, and omp's own `omp shell` in Commands & terminal, and turning it off ends the ones remote pages had open. A terminal only takes input from the page that has it.

### Edit files in the Files tab

- The large view of a text file has **Edit**: a code editor (syntax colours, search with ⌘F, undo) that saves with ⌘S or Save. Line endings and a byte-order mark are kept, and so is the file's mode.
- If the file changed on disk since you opened it, saving says so and offers **Reload** (drop your text) or **Overwrite**. Leaving with unsaved text (closing the view, another file, another conversation, Back) asks first.
- Only whole UTF-8 text files where an upload is allowed can be edited: never a secret, a protected place or the app's own data. A remote page needs Settings › Remote access › file transfer set to full. The editor is loaded only when you press Edit.

### macOS menu bar icon

- The menu bar icon is there while the app has its window too (Settings › Quitting the app › **Always show the menu bar icon**, on by default); in the background it is always there.
- Its menu says how many conversations work, wait for you and are paused, and has **Pause All Conversations** and **Resume All Paused Conversations**.
- One line per provider shows what is left of your quota and when it resets, read when the menu opens (at most once a minute). The menu follows the page's language.

### Model guidance

- New chat's control is a chip, **Guidance: <name>** or **Guidance: off**, that opens a short list like the model picker: each template with a one-line summary, its full text under the pointer, and *Write your own…*.
- Settings › Model guidance lists templates by name and summary and says which one **new chats start with**. Open a template to edit it, make it the default, duplicate or delete it, or reset a shipped one you changed.

### Quick prompts and the guard

- Quick prompts ship five presets: Review my changes, Write tests for this, Summarize & next steps, Commit the work, Simplify what you wrote. A preset added in a later version joins your saved list once; one you removed stays removed, and Restore keeps your own prompts. Guidance templates work the same way.
- Guard dangerous commands: the reviewer rules tuned on real use are now the default (version 3). They also allow filing, commenting on and closing issues of the project's own GitHub repository (`gh issue create/comment/edit/close`). Reading a credential (SSH and GPG keys, cloud and registry tokens, `.netrc`, git credentials, the macOS keychain) is a kind of its own, **secret read**, which is never allowed without asking, whether by a shell command, the read tool or code.

### Fixes

- A subagent's *Retrying…* label goes as soon as it streams again, instead of staying until it ends.
- macOS: the window opens at the size and place you left it (the frame was lost on every reopening); pop-out windows keep their size.
- Settings search: Enter takes the first result, even when the mouse pointer rests where the list opens or a card loads after you typed; a result is chosen only by the arrow keys or by moving the pointer over it (#679).
- `bench-gate` refuses a `--max-load` above the benchmark's own limit at once instead of waiting and failing every run (#662), and names the busiest processes while it waits and when it refuses (#666).

### Performance

- The bench gate deferred since v0.11.13 ran, v0.11.12 against v0.11.17 (#645). The machine was busy, so every run in it is **provisional**. With that caveat: two runs of v0.11.12 agreed within 1.5 %, and against both, v0.11.17's server held 13–43 % more memory and the first page load fetched 22 % more JavaScript (#678, open). A clean run on a quiet machine is still to come.
- v0.11.18 against v0.11.17, from one provisional run of the idle server and the first page load only: the idle server's memory was 11 % lower, and the first page load fetched 1.9 % more JavaScript. Memory with sessions listed, open or streaming was not measured for v0.11.18.

## 中文

### 用“完整 / 轻量”取代“在线 / 离线”

- **完整**就是原来的在线：按你现有的 omp 配置运行。**轻量**只加载你在设置里选定的工具、MCP 服务器和技能，把上下文窗口留给真正的工作；它可以用**你自己的模型**，也可以像原来的离线模式一样用**本地服务器**（oMLX、Ollama 或 LM Studio）的模型。
- 模式属于每个对话。新建对话里，其他选择器旁边多了一个**完整 / 轻量**标签，下一个新对话会使用你上次在那里选的模式。“当前对话”可以切换已打开的对话：它的 omp 会重启，并以另一种模式接着同一个对话；空闲时立即切换，正在工作时等这一轮结束再切换（会写明在等，也可以撤回）。
- 轻量模式的对话，标题栏会显示**轻量**或**轻量 · 本地**。侧边栏的在线/离线开关已经移除，设置里的“模式”改名为**完整 / 轻量**，并可以选择轻量模式用你的模型还是本地服务器。
- 原来的设置会保留：离线变成使用本地服务器的轻量模式，服务器、地址、模型、工具、MCP 服务器和技能都不变；在线变成完整模式。

### 设置分成五页

- 设置不再是一长列，而是五页：**外观与布局**、**对话与文件**、**模型与账号**、**审批与安全**、**应用与系统**，每页有自己的地址（`#/settings/<页>`）和滚动。`#/settings` 打开你上次所在的那一页。搜索仍能找到任何一页上的设置并带你过去，指向某张卡片的链接（来自提示或快捷键列表）也会打开对应的那一页。

### 右侧面板：标签随你摆放，还有终端

- 可以把右侧面板一个窗格里的标签拖到另一个窗格，也可以用它的菜单移动；一个标签只在一个窗格里，移过去就从原来的窗格消失。布局和以前一样会被记住。
- 新增**终端**标签：在对话的文件夹里运行你的登录 shell（`$SHELL -l`），每个对话一个。切换标签、窗格或对话时它继续运行，回来时显示这期间的输出；“重启”、页面关闭或 `exit` 时结束。在后台运行之后，应用的窗口会把它的终端接回来。
- 远程页面（经隧道）默认可以打开终端。设置 › 远程访问 › **允许远程页面打开终端** 可以关掉：服务器会拒绝登录 shell，也会拒绝“命令与终端”里 omp 自己的 `omp shell`，关掉时远程页面已经打开的这些终端也会结束。终端只接受拥有它的页面的输入。

### 在“文件”标签里编辑文件

- 文本文件的大视图有了**编辑**：一个代码编辑器（语法着色、⌘F 搜索、撤销），用 ⌘S 或“保存”保存。行尾和字节顺序标记保持原样，文件权限也不变。
- 打开之后磁盘上的文件又被改过时，保存会提示，并提供**重新载入**（放弃你的修改）或**覆盖**。有未保存的修改时离开（关闭视图、换文件、换对话、后退）会先询问。
- 只有允许上传的位置里完整的 UTF-8 文本文件可以编辑：绝不包括密钥文件、受保护的位置或应用自己的数据。远程页面需要把设置 › 远程访问里的文件传输设为完整。按下“编辑”时才加载编辑器。

### macOS 菜单栏图标

- 应用有窗口时菜单栏图标也在（设置 › 退出应用 › **始终显示菜单栏图标**，默认开启）；在后台时它总是在。
- 菜单说明有几个对话在工作、在等你、已暂停，并有**暂停所有对话**和**继续所有已暂停的对话**。
- 每个提供商一行，显示额度还剩多少、何时重置，在菜单打开时读取（最多一分钟一次）。菜单文字随页面语言。

### 模型指引

- 新建对话里的控件变成一个标签，显示**模型指引：<名称>**或**模型指引：关**，点开是和模型选择器一样的短列表：每个模板附一行说明，鼠标指着时显示全文，还有“自己写…”。
- 设置 › 模型指引按名称和说明列出模板，并写明**新建对话默认使用**哪一个。打开一个模板可以编辑、设为默认、复制、删除，改过的内置模板还可以还原。

### 快捷提示与防护

- 快捷提示自带五个预设：审查我的改动、为这个写测试、总结并列出下一步、提交这些工作、简化你写的代码。以后版本新增的预设会加入你保存的列表一次；你删掉的不会回来，“恢复默认”会保留你自己的提示。模型指引模板也是这样。
- 看守危险命令：根据实际使用调好的审核规则成为默认（第 3 版），并允许在项目自己的 GitHub 仓库里创建、评论和关闭 issue（`gh issue create/comment/edit/close`）。读取凭据（SSH 和 GPG 密钥、云服务和包仓库的令牌、`.netrc`、git 凭据、macOS 钥匙串）单独成为一类**读取密钥**，不管是用 shell 命令、读取工具还是代码，都不会不经询问就放行。

### 修复

- 子智能体的“正在重试…”标签在它重新开始输出时立即消失，不再一直留到它结束。
- macOS：窗口会在你上次离开时的大小和位置打开（以前每次重新打开都会丢失）；弹出窗口保留自己的大小。
- 设置搜索：回车总是选第一个结果，即使鼠标指针正好停在列表出现的位置，或者某张卡片在你输入之后才加载；只有方向键或把指针移到结果上才会选中别的结果（#679）。
- `bench-gate` 遇到高于基准测试自身上限的 `--max-load` 时立即拒绝，而不是等待后让每一轮都失败（#662）；等待时和拒绝时会说出最占 CPU 的进程（#666）。

### 性能

- 自 v0.11.13 起推迟的性能门槛跑了一次：v0.11.12 对比 v0.11.17（#645）。机器当时很忙，所以其中每一轮都是**临时的**。在这个前提下：v0.11.12 的两轮彼此相差不到 1.5%，与两轮相比，v0.11.17 的服务器多占 13–43% 的内存，首次加载页面多下载 22% 的 JavaScript（#678，未解决）。在空闲机器上的正式测量还没有做。
- v0.11.18 对比 v0.11.17，只来自一轮临时测量，而且只测了空闲服务器和首次加载页面：空闲服务器的内存少了 11%，首次加载页面多下载 1.9% 的 JavaScript。列出、打开或流式输出会话时的内存没有为 v0.11.18 测量。
