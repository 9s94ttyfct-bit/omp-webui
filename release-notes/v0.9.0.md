## 引导式目标设定与权限

- 在"每次询问"和"命令询问"权限模式下,引导式目标设定不再先弹出"允许工具:propose_goal"的确认,目标提案卡片是你看到的第一个询问。(#162)
- 为对话选过的权限模式,在该对话分支(branch)或分叉(fork)到新会话文件后会一起带过去。(#163)
- 引导式目标设定的提问过程不再随 omp 进程一起消失:空闲进程被回收、对话交给终端或服务器重启后,再次打开这个对话时引导栏和"提出目标"工具会自动恢复;确认、取消、直接设定目标,或对话已有目标(包括在终端设置的)时不会恢复。(#164)
- 引导式目标设定的第一条消息显示为一行紧凑的标签"引导式目标设定 · 你的想法",说明可展开查看且不能编辑;侧边栏用你的想法命名这个对话。(#165)
- 需要你回应的提案、权限确认和提问卡片出现时会通过读屏软件播报,并在你没有输入内容时把焦点移到卡片上,处理完后焦点回到原处。(#166)
- 引导进行中直接设定目标会结束引导;已有引导时再开始会被拒绝;取消一个还在排队的引导只会把它撤出队列,不会中止正在运行的回合。(#167)

## 子代理与状态

- 手机上展开"任务"列表时,列表限高约三分之一屏并在内部滚动,对话和输入框不再被挤出屏幕。(#174)
- 已取消、已结束或所在进程退出的子代理不再显示"运行中的工具"和转圈动画。(#175)
- 子代理视图只有在 omp 不认识该子代理(或进程已不在)时才改读 transcript 文件;偶发的"连接中断"会自动重试,不再每 2 秒拉取整份会话文件。(#176)
- 子代理的实时状态不再无限增长:工具结束后释放中间输出和参数,只保留最近 20 个已完成的工具,子代理结束后清除流式消息。(#177)
- 服务器把每个子代理的流式消息更新合并为约每 100 毫秒一次,大幅减少广播量。(#178)
- 重新连接或进程退出后,"运行 X 分钟"的计时不再沿用之前轮次的旧时钟。(#179)

## 离线模式与模型预设

- 离线对话里的模型预设选择器现在是禁用状态并附带说明;快捷键不再起作用,也不会再发送 `/modelpreset`,也无法在离线对话中"另存为预设";设置页的"模型角色"和"预设"在选择离线模式时会提示它们只适用于在线模式。(#156)
- 离线/在线的上下文测量会在实际使用的模型、离线 `models.yml` 模型条目(如 `contextWindow`)、`skills/` 目录或 `AGENTS.md` 变化后重新测量。(#157)
- 设置 › 模式会列出已选择但不在 `mcp.json` 里的 MCP 服务器,可一键从列表中移除;进入离线模式时提醒一次。(#158)
- 离线模式拒绝 `--model`、`--smol`、`--slow`、`--plan`、`--models`、`--provider` 等指向非 oMLX 模型的参数,新对话页在离线时也不再显示这些参数。(#159)
- 模型选择按钮的无障碍名称包含当前模型,上下文表格的表头也有了文字。(#160)
- 配置里已有的、名称超过 64 个字符的预设现在可以应用和切换;长度限制只用于新建名称。(#161)

## macOS 应用、Git 与“已加载”面板

- macOS 应用中覆盖已有文件导出对话时,导出现在会真正替换旧文件(失败时恢复原文件);导出失败会弹出提示,完成后在 Finder 中显示该文件。(#153)
- macOS 应用中把文件拖到输入框以外的位置,不再让窗口跳转到该文件;应用会拦截对本机文件和非网页地址的跳转。(#154)
- 对话里启动的 omp 和终端不再继承网页界面服务自己的 `OMP_WEBUI_*` 环境变量,避免端口乱跳、共用数据目录和令牌,以及覆盖应用的 `server.pid`。(#155)
- Git 分支和 PR 标签不再被较慢的旧响应覆盖;在终端切换分支后,新分支的 PR 会自动重新获取。(#168)
- 对话所在文件夹被删除后,"已加载"面板显示"文件夹已不存在",不再误报 omp 找不到。(#169)
- 已暂停的对话打开"已加载"面板时显示一条说明,并仍列出插件和规则,不再每个分区各报一次错。(#170)
- Git 游离 HEAD 状态有了可供读屏软件朗读的文字;"已加载"面板中过长的说明可点击或聚焦展开;`mcp_prompt` 来源有了中英文标签。(#171)
- Git 状态检查会复用刚刚开始的检查,超时的仓库 30 秒内不再重复检查。(#172)
- 刷新"已加载"面板失败时,在旧内容上方显示警告条和"重试",不再静默保留过期内容。(#173)
