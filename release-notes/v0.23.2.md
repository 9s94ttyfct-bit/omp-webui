## English

### Fixes

- **Signing in to a model provider from another device works.** In Settings › Accounts, opened in a window onto another Mac or over remote access, "Open the sign-in page" did nothing: it pointed at omp's short `localhost` address on the computer omp runs on, which is not this device's. It now opens the provider's own sign-in page. Providers that send the browser back to omp's `localhost` (ChatGPT/Codex, Anthropic) then show a page that does not load; the card says so: copy that page's whole address from the address bar and paste it into the box below. The computer omp runs on needs v0.23.2, since it serves the page.
- **Notifications in a window onto another Mac show their real state.** Settings › Notifications in that window was always off and could not be changed, even when this Mac's Macs menu showed that Mac's notifications. It is now the same tick as the menu: it shows whether they are on, turning it on asks macOS as the menu does, and either one follows the other. Both this Mac's app and the other Mac need v0.23.2; with an older app the box stays off and points to the menu.
- **A checkbox question no longer jumps at each pick.** In the agent's `ask` form, ticking an option made the question vanish and come back while omp asked again; it now stays on screen until omp's next question arrives, even when that takes a few seconds.
- **The Settings index no longer overlaps the title.** In the macOS app, at some window widths the index's rows were drawn over the page title and the search box.

## 中文

### 修复

- **可以从另一台设备登录模型服务了。** 在连到另一台 Mac 的窗口里或通过远程访问打开“设置 › 账户”时，“打开登录页面”点了没有反应：它指向的是运行 omp 的那台电脑上的 `localhost` 短地址，而不是你这台设备的。现在会直接打开服务商自己的登录页。登录后会跳回 omp 的 `localhost` 的服务商（ChatGPT/Codex、Anthropic）随后会显示一个打不开的页面，卡片上会提示：从地址栏复制那个页面的完整地址，粘贴到下面的输入框里。运行 omp 的那台电脑需要 v0.23.2，因为页面由它提供。
- **连到另一台 Mac 的窗口里，通知开关显示真实状态。** 以前那个窗口里的“设置 › 通知”总是关着且不能改，即使这台 Mac 的“Macs”菜单里已经为那台 Mac 打开了通知。现在它和菜单是同一个勾：显示是否开启，开启时会像菜单一样请 macOS 允许，任何一边改了另一边都会跟着变。这台 Mac 的应用和那台 Mac 都需要 v0.23.2；应用是旧版时，勾选框仍然关着，并提示去菜单里设置。
- **多选问题每次勾选不再跳动。** 在智能体的 `ask` 表单里，勾一个选项后问题会先消失，等 omp 再问一次才回来；现在它会一直留在屏幕上，直到 omp 的下一个问题到来，即使要等几秒。
- **设置页的目录不再盖住标题。** 在 macOS 应用里，窗口处于某些宽度时，目录的条目会画在页面标题和搜索框上面。
