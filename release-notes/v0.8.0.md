这一版把终端界面里能看到、网页里看不到的内容补齐了，并修复了目标无法真正暂停的问题。

## 修复：目标的暂停与继续

- 以前点“暂停目标”只会把状态改成“已暂停”，正在进行的回合会继续跑，甚至可能把目标直接标记为完成，之后点“继续”就会报错“没有可继续的目标”。现在“暂停”会让代理立刻停下，目标保持暂停；“继续”后代理会自动开始下一轮工作。

## 对话里显示的内容

- **工具结果里的图片**：读取图片、截图等工具返回的图片现在直接显示为缩略图，点击查看原图；折叠的卡片上会标注“N 张图片”。
- **顾问（advisor）备注**：显示为卡片，按严重程度标注，最多列出 3 条，其余显示“另有 N 条”；回合折叠后依然可见，工作摘要里也会提示阻断项。不再出现原始的 `<advisory>` 标签。
- **Claude 的“旁白”**：Claude 写给你看的旁白现在作为回答正文显示，不再折叠进“思考过程”。
- **规则（TTSR）**：规则触发时显示“已应用规则：<规则名>”，连续触发的合并为一行；已保存的规则提醒按规则名显示。
- **模型回退**：发生回退时会显示原因，以及“已在 … 上成功完成请求”；已保存的回退切换会特别标注，折叠后依然可见。
- **后台任务、受监管进程和代理间消息（IRC）**：按类型显示，例如“✓ 后台任务已完成 [eval] bg_1 (10.0s)”和“来自 Main 的 IRC 消息”卡片，不再暴露内部包装标签；实时转发的 IRC 消息也会显示。

## 状态信息

- **待办条**：目标栏旁边新增待办条，显示完成进度、进行中的任务和受阻数量，点击展开完整列表；代理留着未完成的待办就停下时，会显示 omp 的提醒。“待办”标签页新增完成计数、各阶段进度和受阻原因。
- **用量限制和快速模式**：状态栏用 omp 的原话显示 Claude 用量限制所处的阶段（例如“低优先级直到 14:30 · 剩余 62%”“已达上限 · 正在收尾 · … 重置”），快速模式生效时显示 ⚡。
- **通知与上下文压缩**：普通（info）通知现在也会显示，并注明来源；压缩进行时会说明原因（例如“检测到上下文溢出，自动交接…”），结束后显示结果（完成、取消或失败原因）。
- **git 分支和 PR**：状态栏显示当前分支、已暂存 / 未暂存 / 未跟踪的文件数，以及对应的 PR 链接（需要已安装并登录 `gh`）。

## “本对话已加载”面板

- 新增面板，列出这个对话可用的工具（包括按服务器分组的 MCP 工具）、斜杠命令及其来源、MCP 服务器、技能、插件和规则。可以从顶栏按钮或“⋯”菜单打开，也可以在输入框里输入 `/status`、`/extensions` 或 `/skills` 打开。

## 测试

- 从 macOS 应用里打开的终端会带着应用的环境变量，测试服务器以前会因此加载已安装应用的旧版本界面；现在测试会忽略这些变量。
