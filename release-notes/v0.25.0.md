## English

A full audit of the code (`docs/audit/v0.25.0.md`): 19 findings, each filed as an issue (#189–#207) and fixed in this release.

### Remote pages and the Guard

- **A page that holds only the access token can no longer reach the settings only this computer may change.** A command it ran on this computer (its `!command`, its terminal, its agent) could call the server's owner-only routes from the loopback and, for example, turn the Guard off (#189).
- **"Let remote pages open a shell" off now means no command at all.** With the switch off, a page that holds only the token gets no terminal, no `!command`, and only harmless options for a new chat; the turns it starts are locked to what it may do. The switch stays on by default (#190).
- **The Guard cannot be turned off from inside a guarded conversation.** A write through a glob (`*.risk`) or a variable (`$TMPDIR/…`, `D=~; … > $D/.zshrc`) could reach the gate's own state; it is now reviewed as a write to a protected file (#191). Commands run through `arch`, `script`, `sandbox-exec`, `flock`, `watch`, `parallel`, `busybox`, `/usr/bin/time` and other wrappers are read for what they run (#192).

### Conversations

- **A conversation whose subagent still works is busy.** With omp 18.21 or later, Stop's fallback could end the main run while a subagent waited to retry; Delete, Move, a mode switch or the idle reaper then cut the subagent off. They now say to stop it first (#194).
- **What Stop takes back from the queue is kept when you open another conversation meanwhile.** Stop is answered when the turn is over, seconds later; the withdrawn messages now wait in that conversation's message box instead of being lost. The same for a queued-message edit, an edit or a regeneration that fails (#198).
- **A slash command already taken by the server is not given back after a dropped connection,** where it could have been sent twice (#199).
- **Stop of a `!command`, the side question's Stop and the goal proposal's Cancel say when they fail** (#200).
- Two errors in Settings (Start at login, Notifications) are translated (#201).

### Built-in browser

- **On Windows the browser's download is unpacked by Windows' own `tar`,** not by a GNU tar that Git for Windows or MSYS2 put first on PATH, which cannot read zips (#205).

### Tests and release

- CI's actions are pinned to their commits (#203); the Guard's macOS-only case (#202) and the end-to-end tests that need a model login (`bun run test:live:e2e`, #204) now run in the release; `bun run parity` fails when omp's commands could not be read (#206); the contract tests pass against omp 18.21+ (#193); a flaky plugins test names its cause (#195); dead code removed and a stale doc path fixed (#196, #197, #207).

## 中文

对全部代码做了一次审查（`docs/audit/v0.25.0.md`）：发现 19 个问题，都提了 issue（#189–#207），并在这个版本里修复。

### 远程页面与安全守卫

- **只持有访问令牌的页面再也无法改动只有这台电脑才能改的设置。** 它在这台电脑上运行的命令（它的 `!命令`、终端或智能体）以前可以从回环地址调用服务器的本机专用接口，例如关掉安全守卫（#189）。
- **关闭"允许远程页面打开 shell"后，远程页面不能再运行任何命令。** 开关关闭时，只持有令牌的页面没有终端、没有 `!命令`，新对话只能用无害的选项，它发起的轮次也被限制在它有权做的范围内。这个开关默认仍是开启的（#190）。
- **受守卫保护的对话无法从内部关掉守卫。** 以前通过通配符（`*.risk`）或变量（`$TMPDIR/…`、`D=~; … > $D/.zshrc`）的写入可以改到守卫自己的状态；现在它们被当作对受保护文件的写入来审查（#191）。通过 `arch`、`script`、`sandbox-exec`、`flock`、`watch`、`parallel`、`busybox`、`/usr/bin/time` 等包装命令运行的命令，会按它实际运行的内容判断（#192）。

### 对话

- **子智能体还在工作的对话算作忙碌。** 在 omp 18.21 及以上版本里，停止的兜底操作可能结束主运行，而子智能体还在等待重试；这时删除、移动、切换模式或空闲回收会把子智能体中断。现在它们会提示先停止它（#194）。
- **停止时从队列取回的消息，在你同时打开别的对话时也会保留。** 停止要等这一轮结束才有回应，可能要几秒；取回的消息现在会留在那个对话的输入框里，不再丢失。修改排队消息、编辑或重新生成失败时也是如此（#198）。
- **服务器已经收下的斜杠命令，在连接断开后不会再还给你**，以前可能因此被发送两次（#199）。
- **停止 `!命令`、停止旁问、取消目标提议失败时会提示**（#200）。
- 设置里的两条错误信息（开机启动、通知）已翻译（#201）。

### 内置浏览器

- **在 Windows 上，浏览器的下载包由 Windows 自带的 `tar` 解压**，而不是 Git for Windows 或 MSYS2 放在 PATH 前面、读不了 zip 的 GNU tar（#205）。

### 测试与发布

- CI 用到的 action 都固定到具体提交（#203）；守卫只在 macOS 上运行的用例（#202）和需要模型登录的端到端测试（`bun run test:live:e2e`，#204）现在会在发布时运行；读不到 omp 的命令时 `bun run parity` 会失败（#206）；契约测试在 omp 18.21+ 上通过（#193）；一个偶发失败的插件测试会写明原因（#195）；删除了无用代码，修正了文档里过时的路径（#196、#197、#207）。
