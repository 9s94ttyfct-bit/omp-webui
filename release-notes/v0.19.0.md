## English

### Plugins: filters

- **Discover filters by marketplace, category and installed or not**, with a sort by name, marketplace or category. Each filter lists only the values the list has, with how many plugins choosing it would show; the text field now matches authors, categories, tags and keywords too. Each plugin shows its category, how many skills it brings, its author, tags and homepage, read from the catalog omp caches for the marketplace.
- **Installed plugins filter by source and by on or off.**

### Skills: switched on and off

- **Every skill omp finds has a switch** on the Plugins page's Skills tab: *All folders* turns it off or on in omp's global list (`disabledExtensions`, what the terminal's Extension Control Center writes). A skill that is off stays listed, so it can be turned on again.
- **With a project folder chosen, a second switch, *This project***, turns it off or on in that folder alone. omp lets a project's `.omp/config.yml` replace the global list, so the first change copies the global list there; the page says when a project has its own list and offers *Use the global list* to go back. Only that key of the file is rewritten: comments and other settings stay, and a file it cannot change safely is left alone with the reason shown.
- **Select several skills and switch them together**, in all folders or in the project.
- **Filter skills by source, level and on or off**; open a skill's `SKILL.md` (read only) from its path; the registry search sorts by best match, downloads or name and can hide deprecated skills.
- Running conversations pick a switch up by themselves: omp rediscovers its skills when its config changes.

### Usage & cost: conversations, models, tools, errors, time of day

- **Most expensive conversations are those of the range shown**, not of all time: each with its cost, requests, tokens and the models it used, its subagents' and advisor's share included, the top 20. A row opens its conversation; one moved to another project folder is counted as one, at the place it is now.
- **Model comparison**: per model, cost per request, cost per million tokens, cache hit, output tokens per second, time to first token and error share; click a column to sort by it.
- **Tools**: each tool's calls, errors, error share and average result size in the range.
- **Most frequent errors**: the error messages of the range by model, with how often each came and when last.
- **Time of day**: requests and cost by hour of the day in your own time zone, as a heat strip.
- A statistics database from an older omp without what one of these parts reads leaves that part out; the rest of the page stays.

### Windows on Arm

- **A Windows launcher for Arm64 PCs**, `omp-webui-vX.Y.Z-windows-arm64.zip`, built natively next to the x64 one. Updates pick the zip for the launcher's own processor, so an x64 launcher running under emulation on an Arm PC stays on x64 until you install the Arm build. On Windows on Arm the built-in browser is not available (Chrome for Testing has no Arm build for Windows), and cloudflared runs as its emulated x64 build.

## 中文

### 插件：筛选

- **“发现”可按市场、类别、是否已安装筛选**，并可按名称、市场或类别排序。每个筛选只列出列表里实际有的值，并显示选中后会剩下几个插件；搜索框现在也匹配作者、类别、标签和关键词。每个插件会显示它的类别、带有的技能数、作者、标签和主页，这些信息来自 omp 为该市场缓存的目录。
- **已安装的插件可按来源和开启/关闭筛选。**

### 技能：逐个开启和关闭

- **omp 找到的每个技能都有开关**（插件页 › 技能）：“所有文件夹”在 omp 的全局列表（`disabledExtensions`，终端里扩展控制中心写的也是它）中关闭或开启它。关闭的技能仍然列出，方便重新开启。
- **选了项目文件夹时，还有第二个开关“此项目”**，只在该文件夹中关闭或开启。omp 允许项目的 `.omp/config.yml` 取代全局列表，所以第一次修改时会把全局列表复制过去；页面会提示项目已有自己的列表，并提供“改用全局列表”来恢复。文件里只改写这一项：注释和其他设置保持不变；无法安全修改的文件不会被改动，并显示原因。
- **可以多选技能一起开关**，作用于所有文件夹或当前项目。
- **技能可按来源、级别、开启/关闭筛选**；点技能路径可只读查看它的 `SKILL.md`；注册表搜索可按最佳匹配、下载量或名称排序，并可隐藏已弃用的技能。
- 正在运行的对话会自动生效：omp 在配置变化时会重新发现技能。

### 用量与费用：对话、模型、工具、错误、时段

- **“费用最高的对话”改为所选时间范围内的**，不再是全部时间：每个对话显示费用、请求数、token 数和用到的模型，含子代理和顾问的份额，列出前 20 个。点一行即可打开该对话；移到其他项目文件夹的对话算作一个，显示在它现在的位置。
- **模型对比**：每个模型的每次请求费用、每百万 token 费用、缓存命中、输出 token/秒、首 token 延迟和错误率；点列名即可按该列排序。
- **工具**：时间范围内每个工具的调用次数、错误数、错误率和平均结果大小。
- **最常见的错误**：时间范围内按模型列出的错误信息，以及出现次数和最近一次的时间。
- **一天中的时段**：按你所在时区的小时统计请求数和费用，以热力条显示。
- 旧版 omp 的统计数据库若缺少某部分所需的数据，只会隐藏那一部分，页面其余内容照常显示。

### Windows on Arm

- **为 Arm64 电脑提供的 Windows 启动器** `omp-webui-vX.Y.Z-windows-arm64.zip`，与 x64 版一起原生构建。更新会按启动器自身的处理器选择对应的 zip，因此在 Arm 电脑上以模拟方式运行的 x64 启动器会继续使用 x64 版，直到你安装 Arm 版。Windows on Arm 上没有内置浏览器（Chrome for Testing 没有 Windows Arm 版），cloudflared 以模拟的 x64 版运行。
