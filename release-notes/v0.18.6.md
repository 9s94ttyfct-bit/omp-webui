## English

### Remote access on Linux and Windows

- **Remote access now works on Linux and Windows too**, not only on the Mac: the Cloudflare tunnel, Cloudflare Access and pages over a network address.
- **Install cloudflared without Homebrew**: on Linux and Windows the Install step downloads Cloudflare's own cloudflared for your system from its latest GitHub release, checks its SHA-256 against the one GitHub lists, and keeps it in omp-webui's data folder. A cloudflared already on your `PATH` is used first. The Mac still installs it with Homebrew.
- **Confirm risky commands from remote pages understands Windows**: `cmd.exe` and PowerShell commands (`del /s`, `rd /s`, `Remove-Item -Recurse`, `iwr … | iex`, `-EncodedCommand`, `reg`, `schtasks`, `runas`, …) and Windows paths (`C:\Users\…`, `%USERPROFILE%`, `$env:APPDATA`, the Startup folder) are checked like their macOS and Linux counterparts. On Windows the Terminal tab's remote shell is PowerShell.

### Start at login

- **Settings › App & system › Start at login** (off by default) starts omp-webui in the background when you log in. The Mac app opens no window, only its menu bar icon; it appears in System Settings › General › Login Items. On Windows the launcher starts minimized in the taskbar, and on Linux without a window (`omp-webui --stop` stops it); neither opens a page until you open omp-webui.

### Menu bar icon (Mac)

- **A click on the menu bar icon opens the app**; a right click (or Control-click) shows its menu as before.
- **The ✓ beside the icon goes away as soon as you look at the finished conversation**, in the app's window, a pop-out or a browser tab on this Mac. It no longer stays until you open the menu, and it is no longer cleared just because the app came to the front.

### Built-in browser for agents

- **Downloads work**: an agent's `waitForDownload` and download folder failed with "Browser target is not found".
- **Older conversations' pages keep working**: in Chrome for Testing only the newest conversation's page counted as visible, so animations, lazy loading and clicks stalled on the others.
- **WebMCP is on** in the built-in browser, and agents are told how to reach the extra pages a site opens.

## 中文

### Linux 和 Windows 上的远程访问

- **远程访问现在也能在 Linux 和 Windows 上使用**，不再只限于 Mac：Cloudflare 隧道、Cloudflare Access，以及通过网络地址访问的页面。
- **不用 Homebrew 也能安装 cloudflared**：在 Linux 和 Windows 上，“安装”一步会从 cloudflared 在 GitHub 的最新发布下载 Cloudflare 官方的对应版本，核对它的 SHA-256 与 GitHub 列出的一致，并保存在 omp-webui 的数据文件夹里。如果 `PATH` 上已经有 cloudflared，会优先使用它。Mac 上仍用 Homebrew 安装。
- **“确认远程页面的高风险命令”认识 Windows 了**：`cmd.exe` 和 PowerShell 命令（`del /s`、`rd /s`、`Remove-Item -Recurse`、`iwr … | iex`、`-EncodedCommand`、`reg`、`schtasks`、`runas` 等）以及 Windows 路径（`C:\Users\…`、`%USERPROFILE%`、`$env:APPDATA`、“启动”文件夹）会和 macOS、Linux 上的对应写法一样被检查。在 Windows 上，“终端”标签页给远程页面打开的是 PowerShell。

### 开机启动

- **设置 › 应用与系统 › 开机启动**（默认关闭）会在你登录时在后台启动 omp-webui。Mac 应用不打开窗口，只显示菜单栏图标；它会出现在「系统设置 › 通用 › 登录项」里。Windows 上启动器最小化在任务栏里启动，Linux 上没有窗口（用 `omp-webui --stop` 停止）；在你打开 omp-webui 之前都不会打开页面。

### 菜单栏图标（Mac）

- **左键点菜单栏图标会直接打开应用**；右键（或按住 Control 点击）仍和以前一样显示菜单。
- **图标旁的 ✓ 在你看过那个已完成的对话后立刻消失**：无论是在应用窗口、弹出窗口，还是这台 Mac 上的浏览器标签页里看的。它不再一直留到你打开菜单为止，也不会仅仅因为应用切到前台就被清掉。

### 给智能体用的内置浏览器

- **下载可以用了**：智能体的 `waitForDownload` 和下载文件夹以前会报错“Browser target is not found”。
- **较早对话的页面也能正常工作**：以前在 Chrome for Testing 里只有最新对话的页面算作可见，其他页面上的动画、懒加载和点击都会卡住。
- **内置浏览器开启了 WebMCP**，智能体也会被告知怎样访问网站额外打开的页面。
