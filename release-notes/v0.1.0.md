omp-webui 的第一个版本：omp 编程智能体的 Web 界面和 macOS 应用。

## 安装

**macOS 应用（Apple Silicon）**：下载 `omp-webui-v0.1.0-macos-arm64.zip`，解压后把 `omp-webui.app` 拖进“应用程序”，双击打开。需要本机已安装 omp。应用只做了临时签名，第一次打开如被拦截，请在“系统设置 › 隐私与安全性”中允许。

**Web 版（需要 Bun）**：从 GitHub Packages 安装 `@9s94ttyfct-bit/omp-webui`，然后运行 `omp-webui`，打开它打印的链接。

## 功能

- 历史会话：按日期和项目分组浏览、全文搜索、快速切换
- 从任意消息分支，在版本之间切换
- 子代理树、状态和完整记录
- 每条消息和每个会话的 token 用量与费用，以及按日 / 按模型统计页
- omp 的全部命令行功能：会话选项、斜杠命令，内置终端运行任意 `omp` 子命令
- 图片附件、`@文件` 补全、单词预测、`!命令`（可停止）、ask/确认对话框
- 中文 / 英文界面，键盘快捷键（按 `?` 查看）
- macOS 应用：原生窗口；端口被占用时自动改用空闲端口；退出时不残留进程
