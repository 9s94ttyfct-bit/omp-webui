## English

### Sidebar

- **The date heading stays at the top of the list** while its conversations scroll under it, and the next one pushes it away as it arrives: a list scrolled into "Previous 30 days" now says which days it shows.
- **The pages at the foot of the sidebar fold into one row of icons** (the arrow beside the version line), so a short window keeps more conversations in sight. The arrow at the end of the row unfolds them again.
- **Search lists the near matches apart**: conversations whose name holds the query only spread out, or that matched by their project's name, come after the others under "Also matching", so they no longer read as the best results.

### The app updates itself

- **Install updates automatically** (Settings › App & system › Updates, off by default): the Mac app and the Windows launcher now download, check and install a new version by themselves and restart, as soon as no conversation is working, paused or waiting. Until then the card says how many conversations it waits for. A version whose automatic install fails, is cancelled or is rolled back is not tried again by itself; the card still offers it.

### Look and layout follow the device

- **Theme, palette, language, the sidebar and side panel widths, the side panel's panes and the folded sidebar footer belong to the device you choose them on.** The pages on this computer still share them (every port, the Mac app, a browser on `127.0.0.1`); a phone or another computer keeps its own and no longer repaints the Mac, nor the Mac it. Every other preference still follows you everywhere.
- **It is a switch**: Settings › Look & layout › Appearance › *Each device keeps its own look and layout* (on). Turn it off to have every device show the same look and layout again, this computer's to start with.

### Conversations

- **Models are named the same everywhere**: a saved conversation's header and the turn stats show the model's name from the catalog (its id in the tooltip), as the picker does, and the picker adds the snapshot date where two models share a name.
- **An approval with a Deny button has no Cancel beside it**; a turn that already has a Retry no longer offers a Regenerate as well; the time under a turn reads "finished 14:02".
- **The chat header no longer shifts** by the width of the guard toggle when a conversation starts or ends: its place is kept.
- **The Info tab keeps up during a turn**: its figures are read again as tools finish, and the active time counts the running turn as it goes instead of jumping when it ends.
- **Pages sit closer to the top** (Settings, Usage & cost, Plugins and the floating sidebar button had a band of empty space above them); the Guard page keeps a readable width on a wide window; the Settings cards' titles no longer have an icon on some and none on others.

### Fixes and polish

- **Light mode** no longer selects an MCP server and a skill by default that a new install does not have: Light now loads only the MCP servers and skills you tick in Settings › Full / Light. A selection you already saved is kept as it is.
- **New chat on a phone**: the new project's name field gets a line of its own, the full width, and the note under it no longer breaks a few letters per line.
- **The sidebar scrolls to the open conversation** when it is opened by its address, Back, the palette or a link, instead of leaving its row hidden below the fold. Your own scrolling afterwards is left alone.
- **Folder paths are shortened from the start** in the conversation's header and on the status line (`…/work/acme-api`), so the folder's own name stays visible.
- **Tool cards**: a search card shows what was searched for (`grep createLimiter`), not only where; an edit or write card names the file as the call wrote it, or relative to the conversation's folder, with the full path in its tooltip; a card whose arguments are one line its header already shows (a `bash` command) no longer repeats them as JSON above the output.
- **Usage & cost**: the daily chart keeps the calendar's spacing, with empty days where nothing was spent, instead of putting days weeks apart side by side.
- **Agent graph** no longer lists New chat's warm-up process as a running conversation, and the tokens and cost over the graph are the whole conversation's ("in all"), the main agent's included: they read "0 tokens" while the main agent's card said 53k.
- **Subagents started by one call** are listed in the call's order in the Jobs block and the Agents tab, as on its task card.
- **A conversation whose file was deleted or moved** says so, without a Retry that cannot help. An address that names no page (`#/garbage`) shows New chat with New chat's address, and the Questions page scoped to one conversation keeps that scope on reload.
- **Smaller things**: a turn that failed before the model answered no longer shows "in 0 out 0 $0"; the Info tab's note no longer names an internal command; the sidebar's sort control shows a focus ring for the keyboard; the computer-load line no longer jumps between one and two lines as a figure goes from one digit to two; the Unattended mode text points to the side panel's Questions tab; commands in the CI and Issues tabs and in the "When omp compacts by itself" card are shown as code; Start the tunnel is a plain button until the tunnel is set up; the folder in a phone's chat header is easier to tap.

## 中文

### 侧边栏

- **日期标题固定在列表顶部**：它下面的对话滚动时标题不动，下一个日期标题到达时把它推走。滚到“过去 30 天”里时，列表会告诉你现在看的是哪段日子。
- **侧边栏底部的页面可以收成一行图标**（版本号那一行旁边的箭头），窗口不高时能多看到几个对话。点这一行末尾的箭头即可重新展开。
- **搜索把相近的结果单独列出**：名称里只是分散含有关键词的字母、或者因项目名匹配到的对话，排在其他结果之后，放在“相近的结果”下面，不再显得像最佳匹配。

### 应用自动更新

- **自动安装更新**（设置 › 应用与系统 › 更新，默认关闭）：Mac 应用和 Windows 启动器会在没有对话正在运行、暂停或等待时，自己下载、校验并安装新版本，然后重启。在那之前，卡片会显示还在等几个对话。自动安装失败、被取消或被回滚的版本不会再自动重试，卡片里仍可手动安装。

### 外观和布局跟随设备

- **主题、配色、语言、侧边栏和侧边面板的宽度、侧边面板的分栏，以及侧边栏底部是否收起，都属于你设置它们的那台设备。**本机上的页面仍然共享这些设置（任何端口、Mac 应用、在 `127.0.0.1` 打开的浏览器）；手机或其他电脑保留自己的设置，不会再改动 Mac 上的外观，Mac 也不会改动它们的。其余偏好设置照旧在所有地方同步。
- **这是一个开关**：设置 › 外观与布局 › 外观 ›“每台设备分别保存外观和布局”（默认开启）。关闭后，所有设备重新显示相同的外观和布局，起初都采用这台电脑的设置。

### 对话

- **模型名称处处一致**：已保存对话的标题栏和每轮统计显示目录里的模型名称（提示里是模型 ID），与模型选择器一致；两个模型同名时，选择器会加上快照日期。
- **带“拒绝”按钮的审批不再另有“取消”**；已经有“重试”的一轮不再同时提供“重新生成”；每轮下方的时间显示为“完成于 14:02”。
- **对话标题栏不再左右跳动**：对话开始或结束时，守卫开关的位置一直保留。
- **“信息”标签页在一轮进行中也会更新**：每个工具完成后重新读取数据，活跃时间随正在进行的一轮实时累计，不再在结束时突然跳变。
- **页面更靠近顶部**（设置、用量与费用、插件，以及浮动的侧边栏按钮上方原有一段空白）；守卫页面在宽窗口里保持易读的宽度；设置卡片的标题不再有的带图标、有的不带。

### 修复与改进

- **轻量模式**不再默认选中新安装里并不存在的 MCP 服务器和技能：现在只加载你在“设置 › 完整 / 轻量”里勾选的 MCP 服务器和技能。已经保存过的选择保持不变。
- **手机上的新对话**：新项目名称输入框单独占一行、占满宽度，下面的说明也不再几个字母一行地断开。
- **侧边栏会滚动到打开的对话**：通过地址、后退、命令面板或链接打开对话时，它所在的行不会再藏在可见区域之外。之后你自己的滚动不会被打断。
- **文件夹路径从开头截断**：对话标题下和状态栏里的路径显示为 `…/work/acme-api`，文件夹自己的名字始终可见。
- **工具卡片**：搜索卡片显示搜索的内容（`grep createLimiter`），而不只是位置；编辑、写入卡片按调用里写的路径或相对对话文件夹的路径显示文件，完整路径在提示里；参数只有标题已经完整显示的一行（如 `bash` 命令）的卡片，不再在输出上方用 JSON 重复一遍。
- **用量与费用**：每日图表按日历间隔排列，没有花费的日子显示为空，不再把相隔几周的日子并排放在一起。
- **代理关系图**不再把“新对话”预先启动的进程列成一个正在运行的对话；图上方的 token 和费用改为整个对话的（“共”），包括主代理自己的：以前主代理卡片显示 53k，上方却写着“0 token”。
- **同一次调用启动的子代理**在“运行中的任务”区和“子代理”标签页里按调用中的顺序排列，与任务卡片一致。
- **文件已被删除或移走的对话**会直接说明，不再提供一个不可能成功的“重试”。不对应任何页面的地址（`#/garbage`）显示新对话，地址也随之改成新对话的；只看一个对话的“问题”页面刷新后仍保持这个范围。
- **其他细节**：模型回答前就失败的一轮不再显示“输入 0 输出 0 $0”；“信息”标签页的说明不再提到内部命令名；侧边栏的排序按钮在键盘聚焦时显示焦点环；电脑负载那一行不再因为某个数字从一位变成两位而在一行和两行之间跳动；无人值守模式的说明改为指向侧边面板的“问题”标签；CI 和 Issues 标签页以及“omp 自动压缩的时机”卡片里的命令以代码样式显示；隧道设置完成前，“启动隧道”是普通按钮；手机上对话标题里的文件夹更容易点按。
