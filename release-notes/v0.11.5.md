## English

### Watch tools work (new)

- Tool cards now open while their tool runs, showing its output as it streams (the newest lines, followed), and fold when it finishes, the way thinking blocks do. Open or fold a card yourself and it stays that way, even after the message is saved.

### OpenAI quota shows the 5-hour window (#335)

- The ChatGPT/OpenAI quota pill now shows what is left in the 5-hour window instead of the weekly one. If the weekly limit is used up, it shows the weekly limit and when it resets. The popover still lists both windows.
- The pill no longer says "used up" or counts down while ChatGPT credits are paying for usage past the plan limit; it shows 0% left for the 5-hour window instead.

### Fixes (#334, #336, #339, #342)

- Opening a conversation or a subagent transcript can no longer hang forever when the background worker that reads it gets stuck: after a time limit the worker is restarted and the page gets an error it can retry. Search has the same protection.
- The test suites run in parallel on every core (the local release check takes about 8 minutes instead of about 27), and tests that measured the machine's spare CPU, memory or clock instead of the behaviour they check no longer fail on a busy machine.

## 中文

### 实时查看工具执行（新功能）

- 工具运行时，对应卡片会自动展开并实时显示输出（显示最新内容并自动跟随），工具结束后自动折叠，和思考块一样。你手动展开或折叠过的卡片会保持你选择的状态，消息保存后也不变。

### OpenAI 额度显示 5 小时窗口（#335）

- OpenAI（ChatGPT）的额度标签现在显示 5 小时窗口的剩余比例，而不是每周窗口；只有每周额度用完时，才改为显示每周窗口和它的重置倒计时。弹出面板里两个窗口仍然都会列出。
- 当 ChatGPT 积分在为超出套餐的用量付费时，额度标签不再显示“已用完”或倒计时，而是显示 5 小时窗口剩余 0%。

### 修复（#334、#336、#339、#342）

- 读取对话或子代理记录的后台线程卡住时，打开对话不会再一直等下去：超过时限后会重启该线程，页面会收到可以重试的错误。搜索也有同样的保护。
- 测试套件现在在所有 CPU 核心上并行运行（本地发布检查从约 27 分钟缩短到约 8 分钟）；原先测量机器空闲 CPU、内存或时钟、而不是所测行为的测试，在机器繁忙时不再失败。
