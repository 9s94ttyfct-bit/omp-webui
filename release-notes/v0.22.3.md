## English

### Updating the app from a phone

- **A page signed in through Cloudflare Access can update the app.** Settings › Updates now works through the tunnel as it does on the Mac: Check now, Download and install, Cancel, and the sidebar's *Update available* line. A page on the network that holds only the access token still cannot.
- **The tunnel comes back after an update.** When the tunnel is running as the app restarts for an update, it starts again with the new version, even if *Start the tunnel with the app* is off, so updating from your phone does not lock it out.

## 中文

### 用手机更新应用

- **通过 Cloudflare Access 登录的页面可以更新应用了。** 经隧道打开的设置 › 更新和在 Mac 上一样能用：立即检查、下载并安装、取消，侧边栏也会显示“有可用更新”。只持有访问令牌的网络页面仍然不能更新。
- **更新后隧道会自动恢复。** 应用为更新而重启时如果隧道正在运行，新版本启动后会重新启动隧道，即使没有打开“随应用启动隧道”，所以从手机更新不会把手机关在门外。
