## English

### Updating the app from a phone

- **A page signed in through Cloudflare Access can update the app.** Settings › Updates now works through the tunnel as it does on the Mac: Check now, Download and install, Cancel, the automatic update switches, and the sidebar's *Update available* line. A page on the network that holds only the access token still cannot, and can no longer turn automatic updates on or off either.
- **The tunnel comes back after an update.** When the tunnel is running as the app restarts for an update, it starts again with the new version, even if *Start the tunnel with the app* is off, so updating from your phone does not lock it out.

### Downloads in the built-in browser

- **Show in Finder says when it cannot.** If a finished download was moved or deleted, or Finder fails to show it, a toast now says so instead of nothing happening.
- **The Downloads list follows its conversation.** When a conversation is moved to another folder or deleted, a Browser tab that shows it gets the new list right away.

## 中文

### 用手机更新应用

- **通过 Cloudflare Access 登录的页面可以更新应用了。** 经隧道打开的设置 › 更新和在 Mac 上一样能用：立即检查、下载并安装、取消、自动更新的开关，侧边栏也会显示“有可用更新”。只持有访问令牌的网络页面仍然不能更新，现在也不能再打开或关闭自动更新。
- **更新后隧道会自动恢复。** 应用为更新而重启时如果隧道正在运行，新版本启动后会重新启动隧道，即使没有打开“随应用启动隧道”，所以从手机更新不会把手机关在门外。

### 内置浏览器的下载

- **“在访达中显示”失败时会提示。** 下载完成的文件被移走或删除了，或者访达无法显示它时，现在会弹出提示，而不是没有任何反应。
- **下载列表跟着对话走。** 对话被移到别的文件夹或被删除时，正在显示它的浏览器标签页会立刻收到新的列表。
