## English

### Resizable sidebar and side panel (#183)

- Drag the edge of the sidebar or the side panel to resize it, or focus the handle and use the arrow keys (Shift for bigger steps, Home/End for the limits). Sizes are remembered, and the conversation always keeps enough room.
- Double-click a handle, press Enter on it, or use Settings › Appearance › Reset to default size to restore the defaults.

### Edit a queued message (#195)

- Click a queued steer or follow-up message to edit it. Saving queues the new text again at the end of the same queue, with its images. Works while the conversation is paused.
- Messages omp has already sent into the running response are marked as locked and can't be edited; if omp delivers a message while you edit it, you're told and nothing is sent twice.

### Send feedback (#192)

- New "Send feedback" in the sidebar, the command palette and the shortcuts help. It guides you through a bug report or a feature request, shows a preview, and opens a prefilled GitHub issue. Tokens, keys, e-mail addresses and your home folder are removed first; diagnostics (app, omp and macOS versions, mode) are optional.

### Star reminder (#193)

- After five days of use, and only while the repository is public, the sidebar asks once whether you'd like to star it on GitHub ("Not now" or "Don't ask again"). The repository is private for now, so it doesn't appear yet.

### Settings starts no omp just to list providers (#180)

- The Accounts section loads only when you choose "Show accounts", and its process stops when you hide it or leave Settings. Running sessions names it "Accounts helper (not a conversation)" instead of "new session".

## 中文

### 可调整大小的侧边栏和侧边面板（#183）

- 拖动侧边栏或侧边面板的边缘即可调整宽度，也可以聚焦拖动条后用方向键调整（按住 Shift 步幅更大，Home/End 直接到最小/最大）。宽度会被记住，对话区始终保留足够的空间。
- 双击拖动条、在拖动条上按 Enter，或在“设置 › 外观”里点击“恢复默认大小”即可恢复默认宽度。

### 修改排队中的消息（#195）

- 点击排队中的引导或后续消息即可修改。保存后，新内容会带着原来的图片重新排到同类队列的末尾。对话暂停时也可以修改。
- omp 已经送进正在进行的回复中的消息会显示为锁定，无法修改；如果在你修改时 omp 恰好把消息送出了，会提示你，并且不会重复发送。

### 发送反馈（#192）

- 侧边栏、命令面板和快捷键帮助里新增“发送反馈”：按步骤引导你描述问题或功能建议，预览后在 GitHub 打开一个已填好内容的 issue。令牌、密钥、电子邮件地址和你的用户主目录会先被移除；诊断信息（应用、omp 和 macOS 版本、模式）可选附带。

### 星标提醒（#193）

- 使用满 5 天后，并且只在仓库公开时，侧边栏会提醒一次是否在 GitHub 给项目加星标（可选“以后再说”或“不再提醒”）。仓库目前是私有的，所以暂时不会出现。

### 设置页不再仅为列出提供商而启动 omp（#180）

- “账号”区域只有在你点击“显示账号”时才会加载，隐藏或离开设置页时它的进程会随之结束。“运行中的进程”里它显示为“账号助手进程（不是对话）”，不再显示为“new session”。
