## English

### Fixes (#347, #348)

- The server stops watching a folder's project config once no running or paused conversation switched to a preset uses that folder, instead of keeping one watcher per folder for as long as it runs.
- Building the installer no longer fails while an omp-webui disk image (for example a downloaded installer) is mounted: the build lays out its own disk on a private mount point.

## 中文

### 修复（#347、#348）

- 当不再有任何运行中或已暂停、且切换过预设的对话使用某个文件夹时，服务器会停止监听该文件夹的项目配置，不再在整个运行期间为每个用过的文件夹各保留一个监听。
- 已挂载 omp-webui 磁盘镜像（比如下载的安装包）时，构建安装包不再失败：构建在私有挂载点上为自己的磁盘排版。
