## English

### Copy files to and from another computer

- **A second tool for remote computers: `remote_copy`.** A conversation that may use a computer from your Macs list can now also copy a file or a whole folder between this Mac and that computer, either way. It goes over the other computer's own connection as HTTP, not through its terminal, so large files are fine: up to 2 GB (and 200,000 files) per copy.
- **Nothing is replaced unless asked.** A copy onto something that exists is refused unless the agent asks to overwrite; a folder is then replaced whole. Each copy is written beside its target and moved into place only when complete, and keeps 1 GB (or 5 %) of the disk free. Copies never go into the home folder itself or into omp-webui's own data, and links that lead outside the copied folder are left out.
- **Approvals on both sides.** `remote_copy` follows the conversation's approval mode. The guard reads a copy to this Mac as a write here (outside the project, protected places), a copy of secrets or protected places, from either computer, as a secret read, and an overwrite as deleting what it replaces, on the side where it is. The approval names the computer.
- **Both computers need this version.** The other computer serves the copy itself: update it to v0.23.1. It logs each copy in its transfer log, with the Cloudflare Access email that asked.

### Fixes and smaller changes

- **A remote command that runs out of time now stops.** When a `remote_run` call timed out or was given up, a command run by a zsh login shell kept running on the other computer. Ending a terminal now hangs up its whole process group (the other computer needs v0.23.1 for this).
- **Checkbox questions show what is ticked.** In a question of the agent's `ask` form with several answers, the options you had ticked showed no tick, and the option under the pointer (or the last one tapped on a phone) looked ticked. Ticked options now have a check mark and the pointer only outlines an option.
- **The sidebar's load line tells the network and the disk.** After CPU, GPU, memory and power it now shows the network's speed received and sent, and the free space of the system's disk, or of the disks chosen for the Host pane in Settings (each named when there are several).

## 中文

### 在两台电脑之间复制文件

- **远程电脑多一个工具：`remote_copy`。** 可以使用 Mac 列表里某台电脑的对话，现在还能在这台 Mac 和那台电脑之间双向复制文件或整个文件夹。它经那台电脑自己的连接以 HTTP 传输，不经终端，所以大文件也可以：每次最多 2 GB（以及 20 万个文件）。
- **不会擅自覆盖。** 目标已存在时，除非智能体要求覆盖，否则拒绝；覆盖文件夹时整个替换。每次复制先写在目标旁边，完成后才移到位，并且保留 1 GB（或 5%）磁盘空间。不会写进主目录本身或 omp-webui 自己的数据目录；指向所复制文件夹之外的链接会被略过。
- **两边都会询问。** `remote_copy` 跟随对话的批准模式。防护机制把复制到这台 Mac 当作这里的写入（项目之外、受保护位置），把从任一台电脑复制出密钥或受保护位置当作读取机密，把覆盖当作删除被替换的内容（在它所在的那一边）。批准卡片会写明是哪台电脑。
- **两台电脑都需要这个版本。** 复制由那台电脑自己提供服务：请把它也更新到 v0.23.1。那台电脑会把每次复制记录在它的传输日志里，并写明发起请求的 Cloudflare Access 邮箱。

### 修复与小改动

- **远程命令超时后会停下。** `remote_run` 超时或被放弃时，由 zsh 登录 shell 运行的命令会在那台电脑上继续运行。现在结束终端会挂断它的整个进程组（需要那台电脑也是 v0.23.1）。
- **多选问题显示已勾选的选项。** 智能体 `ask` 表单里可多选的问题，以前看不到已勾选的选项，而鼠标所在（或手机上最后点过）的选项看起来像被勾选。现在已勾选的选项有勾号，鼠标经过只显示边框。
- **侧栏的负载行显示网络和磁盘。** 在 CPU、GPU、内存和功耗之后，现在显示网络的接收和发送速度，以及系统盘的可用空间；如果在设置里为主机面板选了磁盘，则显示选中的磁盘（多于一块时带名称）。
