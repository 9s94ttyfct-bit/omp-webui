## English

### A browser of its own for every conversation

- omp-webui now has a built-in browser for its agents. Each conversation's agent browses in pages of its own, and the side panel's new **Browser** tab shows that conversation's pages live: the tabs, Back, Forward, Reload, an address field and **New page**. You can click, scroll and type in a page yourself, so you and the agent work on the same page.
- Three sizes: **Desktop** (1280×800 by default, or the size set in Settings › Browser, scaled down to fit the panel), **Panel** (the panel's own size) and **Phone** (390×844, as a phone). The agent's screenshots, the Mac, a browser tab and a phone all show the same layout.
- Under the page, its console: what it logs and the requests that fail. **Send to agent** on an error puts it into the message box.
- **Full screen** shows the browser over the whole window, and **Open in a new window** gives it a window of its own (in the Mac app a real window, which can go full screen too). The side panel then says where it is, with **Show it here** to bring it back.
- In the Mac app the browser is CEF inside the app, and the Browser tab shows the page itself. In a browser tab, on a phone and in the windows onto other Macs it is a live picture of the page that takes clicks, taps and typing. A server running on its own uses Chrome for Testing, which it starts when a conversation first needs it.
- The browser is not installed until you install it: **Settings › App & system › Browser** installs it, updates it and clears its data (logins, cookies, storage). Only a page on this computer, or one signed in through Cloudflare Access with your account, may do that. Until it is installed, omp uses its own hidden browser as before.
- In the Mac app, installing, updating or clearing the browser restarts the app, which loads the browser once per run. While a conversation is still working it asks first, as quitting does.
- One conversation never sees another's pages. Deleting a conversation closes its pages. Pages are not restored when the browser or the app restarts (after an update or Clear).
- No browser omp-webui starts ever asks for the macOS keychain.

### Guidance

- Model guidance is now called **Guidance**: a conversation's standing rules (how to hand work to subagents and which models to use, its language, how it commits, …). It ranks above earlier instructions and recalled memories.
- A change to a conversation's guidance is noted in the conversation: the agent is told the new rules on its next turn, and the transcript shows **Guidance changed** or **Guidance turned off**.

### New chat

- New chat's settings are a bar under the message box, every one always shown: preset, model, thinking, Full/Light, then guard, guidance, permission mode, unattended and goal. On a narrow window they stay in the bar as icons.
- One folder button before the project's name: **New project**, an existing folder, or a recent one, from its menu.

### And

- **Advisor on or off per conversation**: This session › Advanced, and a switch on New chat's bar. It applies from the next turn without a restart, and only to that conversation.
- The chat header names the folder's repository under the title.
- This session: Claude's slow mode (a global setting) moved into Advanced, so the folded panel fits a 1280×800 window again.

## 中文

### 每个对话都有自己的浏览器

- omp-webui 现在为它的智能体内置了浏览器。每个对话的智能体在自己的页面里浏览，侧边面板新增的 **浏览器** 标签页实时显示这个对话的页面：标签、后退、前进、刷新、地址栏和 **新页面**。你也可以自己在页面里点击、滚动、输入，和智能体在同一个页面上一起工作。
- 三种尺寸：**桌面**（默认 1280×800，或设置 › 浏览器里设定的尺寸，缩小后放进面板）、**面板**（面板本身的大小）和 **手机**（390×844，按手机显示）。智能体的截图、Mac、浏览器标签页和手机看到的是同一个布局。
- 页面下方是它的控制台：页面输出的日志和失败的请求。在错误上点 **发给智能体**，就把它放进输入框。
- **全屏** 让浏览器占满整个窗口，**在新窗口中打开** 把它放进单独的窗口（在 Mac 应用里是真正的窗口，也可以全屏）。这时侧边面板会说明它在哪里，点 **在这里显示** 就能把它放回来。
- 在 Mac 应用里，浏览器是应用内的 CEF，浏览器标签页直接显示页面本身。在浏览器标签页、手机上和连到其他 Mac 的窗口里，显示的是页面的实时画面，同样可以点击、轻点和输入。单独运行的服务器使用 Chrome for Testing，在对话第一次需要时由服务器启动。
- 浏览器默认不安装：在 **设置 › 应用与系统 › 浏览器** 里安装、更新和清除它的数据（登录、Cookie、存储）。只有本机上的页面，或通过 Cloudflare Access 用你的账号登录的页面才能这样做。安装之前，omp 和以前一样使用它自己的隐藏浏览器。
- 在 Mac 应用里，安装、更新或清除浏览器会让应用重新启动（浏览器每次运行只加载一次）。还有对话在工作时，它会像退出时一样先问你。
- 一个对话永远看不到另一个对话的页面。删除对话会关闭它的页面。浏览器或应用重启（更新或清除之后）时，页面不会恢复。
- omp-webui 启动的浏览器都不会再请求 macOS 钥匙串。

### 指引

- “模型指引”现在叫 **指引**：对话的常设规则（怎样把工作交给子智能体、用哪些模型、用什么语言、怎样提交……）。它的优先级高于之前的指令和召回的记忆。
- 对话的指引一改，对话里就会留下记录：智能体在下一轮收到新的规则，记录里显示 **指引已更改** 或 **指引已关闭**。

### 新建对话

- 新建对话的设置变成输入框下方的一条栏，每一项都一直显示：预设、模型、思考强度、完整/轻量，然后是守卫、指引、权限模式、无人值守和目标。窗口较窄时它们以图标留在栏里。
- 项目名前只有一个文件夹按钮：从它的菜单里选 **新项目**、已有文件夹或最近用过的文件夹。

### 其他

- **按对话开关顾问（advisor）**：在“当前对话 › 高级”里，新建对话的设置栏上也有开关。从下一轮起生效，不用重启，只影响这个对话。
- 对话标题下方显示文件夹所在的仓库。
- 当前对话面板：Claude 的慢速模式（全局设置）移到“高级”里，折叠时面板又能放进 1280×800 的窗口。
