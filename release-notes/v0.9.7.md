## English

### Edit the todo list (#197)

- Todos can now be edited in the Todos tab and in the list above the message box: finish a task from its state icon, set its state (with a reason when blocked), edit its text, add, remove and reorder tasks and phases, or edit the whole list as Markdown. Changes go through omp's own `/todo import`, so they follow omp's rules and are still there after a resume.

### Turn skills and plugins on and off (#198, #199)

- The Loaded dialog now has switches for skills and plugins. A skill you turn off is added to omp's global `disabledExtensions` setting and omp stops offering it at once. Plugins use `omp plugin enable|disable` and the conversation's skills and commands reload immediately.
- Fixed: disabled marketplace plugins were shown as enabled in the Loaded dialog.

## 中文

### 编辑待办列表（#197）

- 现在可以在“待办”标签页和输入框上方的待办列表里直接编辑待办：点状态图标即可完成任务，可设置状态（受阻时可填写原因）、修改文字、添加、删除、调整任务和阶段的顺序，也可以用 Markdown 编辑整个列表。修改通过 omp 自己的 `/todo import` 完成，遵循 omp 的规则，恢复对话后依然保留。

### 开关技能和插件（#198、#199）

- “已加载”对话框新增技能和插件开关。关闭的技能会写入 omp 全局的 `disabledExtensions` 设置，omp 会立即不再提供它；插件通过 `omp plugin enable|disable` 切换，并立即重新加载该对话的技能和命令。
- 修复：已停用的市场插件之前在“已加载”对话框里仍显示为已启用。
