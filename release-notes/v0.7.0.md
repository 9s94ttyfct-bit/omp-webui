## 新功能：在线模式 / 离线模式

- 侧边栏“新对话”下方新增模式切换；设置 › 模式里可以详细配置。
- **离线模式**：所有模型角色都使用 oMLX 提供的本地模型，模型选择器里只列出 oMLX 模型。工具默认只保留核心集合（read、bash、edit、write、grep、glob、todo），MCP 默认只保留 REA，skills 默认只保留 REA 的技能，个人 AGENTS.md 默认不加载；每一项都可以在设置里调整。插件来源的额外 MCP、skills 也会被挡掉。
- **为什么要这样做**：本机 66K 上下文的 oMLX 模型上，新对话开始前的占用从约 32K tokens 降到约 17K，可用空间从 17.1K 增加到约 32K。设置页可以实测两种模式的上下文占用。
- 离线模式使用 omp-webui 自己的数据目录里单独的 omp 配置，不会改动你 `~/.omp` 里的配置，终端里的 omp 不受影响；对话照常保存在原来的会话目录里，历史记录里都能看到。
- 正在运行的对话保持它启动时的模式，并显示“离线”标记；oMLX 没有运行时会给出明确提示；oMLX 的 API key 只保存在权限为 0600 的文件里，不会出现在任何界面或接口返回里。
- 恢复一个原本用云端模型的对话时，离线模式会改用你选定的 oMLX 模型。

## 新功能：实时观看子代理

- 点击任何子代理（正在运行或已结束），都能看到它完整的对话记录，以及流式输出的文字、思考过程和工具的实时输出；会自动跟随到底部，可以跳到嵌套的子代理，也可以引导或取消。
- 子代理运行时，输入框上方会显示任务列表：类型、模型、名称、描述、进度和已运行时间；超过 3 行会折叠为“另有 N 个”，点击任一行就能打开它的实时视图。
- 正在运行的子代理排在最前面（最近启动的在最上），带转圈和计时。
- 对话的 token 和费用统计现在包含所有子代理（包括嵌套的子代理）；顶栏提示、侧边栏和用量页都会分开显示“主代理 / 子代理”各自的花费。

## 与终端界面一致的信息

- **轮次统计行**：每个代理回合结束后，在回复下方显示和终端一致的统计：完成时间、用时、输入 / 输出 / 缓存 token、首 token 耗时、输出速度；悬停可以看到每次请求各自的耗时。回合进行中会实时显示已运行时间。omp 没有记录的数据会直接省略，不会编造。
- **状态栏**：输入框下方新增与终端底部一致的状态栏：工作时长、模型与思考等级、目标预算（已用 / 总额）、文件夹、费用（主代理 + 子代理）、上下文用量条和窗口大小、运行中的子代理数（点击打开子代理列表）。手机和窄屏上只保留最重要的几项，其余收进“⋯”菜单。
- 长时间运行的回合里，上下文百分比会随每次请求结束刷新。

## 新功能：引导式目标

- “设定目标”改为引导式：可以先写一个粗略的想法，代理会在对话里一次问一个关键问题（适合时用选项让你点选），然后提出最终的目标、验收标准和 token 预算。
- 提议会以卡片显示，每一项都可以直接修改，也可以“要求修改”或取消；只有你确认后才会创建目标并进入目标模式，取消则不会留下任何目标。
- 采访进行时，输入框上方会显示进度条，随时可以“直接设定”或取消；也可以跳过采访直接填写。聊天顶栏、新对话页的目标开关、命令面板和快捷键 ⌘⇧G（Ctrl+Shift+G）都能用。

## 新功能：一键切换权限模式

- 输入框底部新增权限模式切换（快捷键 ⌘⇧A / Ctrl+Shift+A）：每次都询问 / 只询问命令（自动批准文件编辑）/ 全部自动批准。“全部自动批准”会以警示色显示。
- 切换对当前对话立即生效，不需要重启 omp；运行中的回合会从下一次工具调用开始使用新模式，并会提示你。每个对话记住自己的选择；设置里可以设定新对话的默认模式（默认沿用 omp 自己的设置）。
- omp 的批准请求会清楚显示工具名、详细内容，“拒绝”按钮为红色。

## 新功能：模型预设

- 输入框底部新增「模型预设」：一键切换整套模型配置（各角色的模型和思考强度）。当前对话立即生效，切换本身不会调用模型。
- 可以把当前配置“另存为”预设（名称规则与 omp 一致：字母开头，可含字母、数字、`-`、`_`）；重名时需明确选择覆盖。
- 快捷键 ⌘⇧M（其他平台 Ctrl+Shift+M）循环切换预设，并提示切换到了哪一个。
- 设置页新增「模型角色」编辑器：为每个角色选择模型和思考强度，添加或移除角色，设置默认思考强度。还有预设管理：应用、重命名、复制、删除（需确认）；项目配置里定义的预设只读显示。
- 预设直接使用 omp 自带的 `modelPresets` / `modelRoles` 配置，与终端界面共用。

## 对话

- **`!命令`**：`!` 开头的内容在任何状态下都会作为命令运行，不会再被当成排队消息发给模型。运行中的每条命令在输入框上方都有一张卡片，显示命令、已运行时间、“已暂停”标记和“停止”按钮。
- **暂停**：横幅新增“停止”（也可按 Esc），并写明被冻结的命令；暂停后焦点落在“继续”，继续或停止后回到输入框；暂停时的发送按钮改为明确的“继续并发送”。
- **斜杠命令**：命令输出不再夹带终端颜色代码；omp 在此对话里不认识的 `/名称`（如 `/new`、`/tree`、`/resume`）不再白白消耗一次模型调用，而是提示网页里的对应功能，也可以选择“仍然发给模型”。
- **重试与压缩**：失败的回复提供“重试”按钮；自动重试时显示“第 n/m 次重试，x 秒后开始 · 取消”；自动压缩时显示“正在压缩上下文…”；重试成功后，之前的失败只显示为一行灰色提示；同一个错误不再显示两次。
- **↑ / ↓ 翻看历史**：输入框为空或光标在第一行时，按 ↑ / ↓ 可以翻看本对话之前发送过的提示和 `!命令`，离开历史时恢复未发送的草稿。
- **编辑/写入工具卡片**：显示文件路径和增删行数，展开后是红绿着色、带行号的差异视图；原始参数收进开关。
- **思考过程**：打开“保持思考过程展开”后，包含思考步骤的代理回合默认展开。
- **额度胶囊**：在“新对话”页和已保存的对话里也会显示；有多个账号时显示额度最充裕的那个，点击（或用键盘、触摸）可查看每个账号、每个时间窗口的额度。

## 侧边栏、搜索与归档

- 批量操作只作用于当前列表里可见的已选对话，被筛选隐藏的对话不会被计数、归档或删除。删除确认会列出对话标题；在对话框里按 Esc 只关闭对话框，不会退出选择模式。
- 搜索结果每个对话最多显示 3 条，并提示“此对话中还有 N 条”，点击就地展开。
- 已归档的对话：顶栏有“已归档”标记和“取消归档”按钮；向已归档对话发送消息会自动取消归档；搜索面板会标出已归档的对话；归档后可以“撤销”。
- 模型选择器：爱心按钮不再占用 Tab 顺序，在爱心上按 Enter 或空格只会收藏/取消收藏；⌘⇧L（Ctrl+Shift+L）收藏高亮的模型。
- 简体中文界面统一使用“对话”。

## 性能

- 超长对话打开时只渲染最近的消息（“显示更早的消息”可继续加载）：400 轮的对话，页面元素从 3.5 万个降到约 1300 个，打开时不再卡顿。
- 其他对话文件变化时，不再重新下载当前打开的对话；流式输出时，侧边栏不再逐行重绘（1000 个对话时每个 token 的开销从 17.7 ms 降到 3.0 ms）。
- 代码高亮改用 JavaScript 正则引擎并放到 Web Worker 里，不再加载 600 KB 的 WebAssembly；构建产物从 12 MB 降到 7.5 MB；CSP 不再需要 `wasm-unsafe-eval`。
- 超大对话（20 MB 以上）的加载不再阻塞其他请求；加载过的对话通过缓存和 304 直接复用。
- 有对话在等你回答时，浏览器标签页标题会显示数量，例如 `(2) omp`；标签页在后台时回复完成会显示 `✓ omp`。设置里还可以打开系统通知。

## macOS 应用

- 有对话仍在运行时，按 ⌘Q 或关闭窗口会先询问“N 个对话仍在运行——仍要退出吗？”，点“取消”则一切照常运行。
- 应用被强制退出或崩溃后，后台的 omp 及其启动的命令会在约 3 秒内全部结束，不会残留。
- 再打开一份应用不会再停掉正在运行的那份：它会把已运行的应用调到前台，然后自己退出。提示框里不再出现访问令牌。
- 反复刷新“新对话”页面不会每次多启动一个 omp，会复用同一个尚未使用的进程。
- Dock / Finder 图标不再有白色边框；“显示”菜单里不再出现应用不支持的标签页选项。

## 修复

- 切换模型预设后，选择器有时仍显示上一个预设：服务器合并重复的配置读取时，可能把一个在 omp 写入前就开始的读取结果返回给之后的请求。现在服务器只合并尚未开始的读取，并监听 omp 的 `config.yml`，写入后立即通知前端刷新；每次读取也从 6 次 omp 调用减少到 2 次。
- 会话列表在首次扫描完成前被并发请求时，可能返回空列表的问题已修复。
- 新对话页面不会把在线模式下预启动的 omp 进程交给离线对话，反之亦然。
