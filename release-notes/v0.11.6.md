## English

### Model presets belong to the conversation (#344, #345)

- A model preset switch now applies to the current conversation and the subagents it starts from then on. Other conversations, the subagents they start, and the global default are unchanged; new conversations start with the global default. The choice is kept when the conversation is reloaded, resumed or the app restarts.
- New: "Set as default" in the preset menu makes the current preset the global default. Only it and Settings change the default.
- A role added later to the global or the project's config no longer reaches a conversation that was switched to a preset, nor the subagents it starts.

### See what each subagent was told (#343, #346)

- Expand a subagent on its task card, or open it in the Agents tab, to see its assignment: its task and the context shared with every subagent of the call. This works while it runs, after it ends and after a reload. Both render as Markdown, long ones fold behind "Show more", and each part copies as written.
- "View subagents →" now opens the right subagent after a reload.
- A subagent you open in a running task card keeps the card open when the call returns, instead of folding away while you read it.

### Advisor costs are counted (#340)

- A conversation's cost and token totals now include its advisors' requests. omp keeps those in `__advisor.jsonl`, outside the transcript and omp's own session statistics, so they were missing before. The advisor's share is shown next to the subagents' in the header tooltip, status line, sidebar, Usage page and Info tab.

### Notifications in the macOS app (#338)

- The macOS app can now show notifications. Turning them on in Settings shows macOS's own permission prompt; a notification appears when a conversation needs your answer or finishes while you are in another app, and clicking it opens that conversation. If macOS blocks them, Settings tells you to allow them in System Settings › Notifications. The browser version is unchanged.

### Settings fixes (#337, #341)

- Settings › Mode: text you are typing in a backend's address field is no longer replaced when another tab, or a re-read of the settings, changes the state meanwhile; it is saved when you leave the field.
- Settings › Mode: clearing a backend's address could leave the old address in the field without saving the clear. A settings read answered before your change no longer undoes it, and an address you clear or edit right after choosing a backend is no longer overwritten by the field resetting itself.

## 中文

### 模型预设只作用于当前对话（#344、#345）

- 切换模型预设现在只影响当前对话以及它此后启动的子代理；其他对话、它们启动的子代理以及全局默认都不受影响，新对话从全局默认开始。对话重新加载、恢复或应用重启后，选择仍然保留。
- 新增：预设菜单里的“设为默认”会把当前预设设为全局默认。只有它和设置页会修改全局默认。
- 之后新增到全局配置或项目配置里的角色，不再影响已切换到某个预设的对话，也不再影响它启动的子代理。

### 查看每个子代理收到的任务（#343、#346）

- 在 task 工具卡片上展开某个子代理，或在“子代理”标签页里打开它，就能看到它收到的任务说明：它自己的任务，以及同一次调用的所有子代理共享的上下文。子代理运行中、结束后以及刷新页面后都能看到。两部分都按 Markdown 显示，较长的会折叠，点“展开”查看全文，每一部分都可以原样复制。
- 刷新页面后，“查看子代理 →”现在会打开正确的那个子代理。
- 在运行中的 task 卡片里展开某个子代理后，调用结束时卡片会保持展开，不会在你阅读时自动折叠。

### 计入顾问的费用（#340）

- 对话的费用和 token 合计现在包含顾问（advisor）的请求。omp 把这些请求写在 `__advisor.jsonl` 里，既不在对话记录中，也不在 omp 自己的会话统计里，所以以前没有算进去。顾问的份额和子代理的份额一起显示在标题栏提示、状态行、侧边栏、用量页和“信息”标签页中。

### macOS 应用的通知（#338）

- macOS 应用现在可以显示通知了。在设置里开启时会弹出 macOS 自带的权限询问；当对话需要你回答或已完成、而你在别的应用里时，会出现通知，点击即可打开该对话。若 macOS 屏蔽了通知，设置里会提示去「系统设置 › 通知」允许。浏览器版的行为不变。

### 设置修复（#337、#341）

- 设置 › 模式：在后端地址输入框里输入时，如果另一个标签页修改了设置，或页面重新读取了设置，输入的文字不会再被覆盖；离开输入框时照常保存。
- 设置 › 模式：以前清空后端地址后，输入框可能仍显示旧地址，清空也没有被保存。现在，在你的修改之前就已得到回应的设置读取不会再撤销它；选择后端后立即清空或修改地址，也不会再被输入框的重置覆盖。
