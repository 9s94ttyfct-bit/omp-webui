## English

### Send here

- Editing a prompt now offers **Send here**: the edited prompt replaces the original one in the same conversation, which keeps its place, name and settings. The conversation as it was is kept as a branch beside it.

### Projects

- A **project** groups conversations from any folders, and can have a folder of its own. Projects have their own section at the top of the sidebar, above the list by date, and a conversation in a project is no longer listed again by date.
- Move a conversation into a project from its menu, by dragging it onto the project, or several at once with Select. **New chat** inside a project starts the conversation there, and the project's folder button opens its folder in Files.
- The folder groups of earlier versions become projects once. The search funnel's folder grouping is now a simple **Folder** filter.

### Plugins: Discover, Skills and MCP servers

- The Plugins page has new tabs. **Discover** has a card of recommended marketplaces that you add in one click, and the install-by-package form. **Skills** searches and installs skills through `omp skill`: a skill that ships scripts shows them for you to review before it is installed. **MCP servers** searches the official MCP Registry and adds a server to your `mcp.json`; secrets are typed into password fields, and a server that can't be added says why.

### Memory moves into Settings

- Memory is now opened from a card in Settings › Conversations (old `#/memory` links still work). The sidebar no longer lists it.

### The built-in browser updates itself

- A minute after the server starts, and once a day after that, the built-in browser checks for a newer Chrome for Testing, downloads and checks it in the background, and switches to it once no conversation has used the browser for five minutes. The Mac app's embedded browser is updated the next time the app starts. You can turn this off in Settings › Browser.

### Fixes

- **A tool that was already running when the page opened** (the Mac app's window opened again, a reload, a second tab) now shows as running at once: its bar along the bottom of the card and its clock, counted from when it really started. Before, a tool that printed nothing showed as one about to start until it ended.
- **Animations in the Mac app's window** (the spinner and the bar of a running tool, the glow of the running time) no longer step along at a few frames a second after the window is opened again. WebKit kept the animations that began while the page loaded at that rate for as long as they ran.

## 中文

### 在此发送

- 编辑一条提示词时，现在可以选择 **“在此发送”**：编辑后的提示词会在同一个对话里替换原来的那条，对话的位置、名字和设置都不变。原来的对话作为一个分支保留在旁边。

### 项目

- **项目**可以把来自任意文件夹的对话归到一起，也可以有一个自己的文件夹。项目在侧边栏顶部有单独的一栏，位于按日期排列的列表上方；项目里的对话不会再在日期列表里重复出现。
- 可以从对话的菜单把它移到项目里，也可以把它拖到项目上，或用“选择”一次移动多个。在项目里点 **“新对话”** 会直接在该项目中开始对话，项目的文件夹按钮会在“文件”里打开它的文件夹。
- 旧版本的文件夹分组会一次性转换成项目。搜索漏斗里的文件夹分组现在是一个简单的 **“文件夹”** 筛选。

### 插件：发现、技能和 MCP 服务器

- 插件页面新增了几个标签页。**“发现”** 里有推荐插件市场的卡片，一键即可添加，也有按包名安装的表单。**“技能”** 通过 `omp skill` 搜索和安装技能：带脚本的技能会在安装前先把脚本列出来供你查看。**“MCP 服务器”** 搜索官方 MCP Registry，并把服务器添加到你的 `mcp.json`；密钥在密码框里输入，无法添加的服务器会说明原因。

### “记忆”移到了设置里

- “记忆”现在从“设置 › 对话”里的一张卡片打开（旧的 `#/memory` 链接仍然有效）。侧边栏里不再列出它。

### 内置浏览器会自动更新

- 服务器启动一分钟后，以及之后每天一次，内置浏览器会检查是否有更新的 Chrome for Testing，在后台下载并校验，等到五分钟内没有对话使用浏览器时再切换过去。Mac 应用内嵌的浏览器会在下次启动应用时更新。可以在“设置 › 浏览器”里关闭。

### 修复

- **页面打开时已经在运行的工具**（Mac 应用的窗口重新打开、刷新页面、另开一个标签页）现在会立刻显示为运行中：卡片底部有进度光带，计时从它真正开始的时刻算起。以前，一个没有输出的工具在结束前一直显示为“即将开始”。
- **Mac 应用窗口里的动画**（运行中工具的旋转圈和光带、运行时间的闪烁）在窗口重新打开后不再只有每秒几帧、一顿一顿地动。WebKit 会让页面加载期间开始的动画在整个运行过程中都保持这个帧率。
