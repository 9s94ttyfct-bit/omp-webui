## English

### Memory pressure on the sidebar's line

- **The host load line shows the memory pressure after the memory in use.** It reads `CPU 12% · GPU 3% · MEM 61% · Pressure Normal · …`: the memory in use as before, then the pressure as macOS states it (Normal, Warning or Critical), the level Activity Monitor colours its memory pressure graph by. The dot at the end keeps its colour. A computer that states no memory pressure shows none.
- **The memory tile names its badge.** In the host load pane, the badge next to the memory in use now reads *Pressure Normal* instead of *Normal* alone.

## 中文

### 侧边栏这一行显示内存压力

- **本机负载这一行在内存使用量后面显示内存压力。** 显示为 `CPU 12% · GPU 3% · 内存 61% · 压力 正常 · …`：内存使用量和以前一样，后面是 macOS 给出的压力等级（正常、警告或严重），也就是"活动监视器"给内存压力图上色所用的等级。末尾的圆点颜色不变。系统不提供内存压力的电脑上不显示这一项。
- **内存数值块的标签写明是压力。** 本机负载面板里，内存使用量旁边的标签由"正常"改为"压力 正常"。
