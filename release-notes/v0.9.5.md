## English

### Offline mode on Ollama and LM Studio (#186)

- Offline mode now also runs on Ollama and LM Studio, not just oMLX. Settings › Mode lets you pick the backend, edit its address, and see its connection status and the models it serves. Ollama and LM Studio need no models.yml entry; oMLX setups keep working unchanged.
- LM Studio models whose ids contain a slash (e.g. `qwen/qwen3-8b`) used to be hidden in offline mode; they now work.
- A new chat no longer reuses an unused offline process that was started with different offline settings (another backend or model).

## 中文

### 离线模式支持 Ollama 和 LM Studio（#186）

- 离线模式现在除了 oMLX，也支持 Ollama 和 LM Studio。在“设置 › 模式”里可以选择本地后端、修改它的地址，并查看连接状态和它提供的模型。Ollama 和 LM Studio 不需要在 models.yml 里配置；原有的 oMLX 设置保持不变。
- 修复：id 里带斜杠的 LM Studio 模型（如 `qwen/qwen3-8b`）之前在离线模式下会被隐藏，现在可以正常使用。
- 新对话不再沿用以不同离线设置（另一个后端或模型）启动、尚未使用的离线进程。
