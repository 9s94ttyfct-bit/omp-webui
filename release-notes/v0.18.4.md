## English

### Linux

- **omp-webui for Linux**: each release now carries `omp-webui-vX.Y.Z-linux-x64.tar.gz` and `omp-webui-vX.Y.Z-linux-arm64.tar.gz`. Unpack it and run `./install.sh`: it installs omp-webui for your user (`~/.local/share/omp-webui`, the `omp-webui` command in `~/.local/bin`, and an entry in the applications menu). Starting it opens the page in your browser, in a terminal window that is the server's: closing it stops omp-webui. To update, install the new package the same way; `./install.sh --uninstall` removes it and keeps your data. Settings › Updates says when a new Linux package is out.

### Built-in browser

- **Uninstall** in Settings › Browser removes the browser and everything it kept (logins, cookies, storage, cache), after asking. You can install it again. In the Mac app, the app restarts to finish.
- **Use the built-in browser** in Settings › Browser turns it off altogether: the Browser tab leaves the side panel, its pages close, and the agents of your conversations have no browser tool at all until you turn it on again. Turned on, the tab comes back where it was.
- **The Mac app removes the CEF versions an update replaced** when it starts, instead of keeping each one (hundreds of MB each).
- **The console strip works in the Mac app's own windows**: it stayed empty there, because the tab asked the server for the page's frames and console together and the app draws the page itself.
- **The screen no longer freezes after the server or the engine restarts** while the page stays open: the new frames were taken for old ones.
- **A Browser tab told the browser could not be used recovers on its own** once the app's browser is back, instead of waiting for you to switch pages.

### CI tab

- **The CI tab starts on All branches**, and remembers your choice of This branch or All branches on each device.

### Fixes

- A paused conversation that a restarted server could not take over no longer has its settings file written again every 15 seconds.

## 中文

### Linux

- **omp-webui 支持 Linux**：每个发布版本都附带 `omp-webui-vX.Y.Z-linux-x64.tar.gz` 和 `omp-webui-vX.Y.Z-linux-arm64.tar.gz`。解压后运行 `./install.sh`，即可为当前用户安装 omp-webui（`~/.local/share/omp-webui`、`~/.local/bin` 里的 `omp-webui` 命令，以及应用程序菜单中的一项）。启动后会在浏览器中打开页面；同时打开的终端窗口就是服务器本身，关闭它即停止 omp-webui。更新时用同样的方法安装新版本的包；`./install.sh --uninstall` 会卸载它，数据保留。有新的 Linux 包时，“设置 › 更新”会提示。

### 内置浏览器

- “设置 › 浏览器”新增**卸载**：确认后删除浏览器及它保存的一切（登录信息、Cookie、存储和缓存），之后可以重新安装。在 Mac 应用中，应用会重启以完成卸载。
- “设置 › 浏览器”新增**使用内置浏览器**开关，可以彻底关闭它：侧边面板里不再有浏览器标签页，它的页面会关闭，对话中的智能体完全没有浏览器工具，直到你重新打开。重新打开后，标签页回到原来的位置。
- **Mac 应用启动时会删除被更新替换掉的旧 CEF 版本**，不再每个版本都保留（每个几百 MB）。
- **Mac 应用自己的窗口里控制台栏恢复正常**：之前那里一直是空的，因为标签页向服务器同时请求页面的画面和控制台，而应用是自己绘制页面的。
- **服务器或引擎重启后、页面仍开着时，画面不再卡住**：之前新的画面会被当成旧的。
- **浏览器标签页在被告知浏览器不可用后会自行恢复**：应用的浏览器回来后即可使用，不必再切换页面。

### CI 标签页

- **CI 标签页默认显示所有分支**，并在每台设备上记住你选择的“本分支”或“所有分支”。

### 修复

- 重启后的服务器无法接管某个已暂停的对话时，不再每 15 秒重新写一次它的设置文件。
