## English

### A Windows launcher

- Each release now also carries `omp-webui-vX.Y.Z-windows-x64.zip` (Windows 10 or later, x64). Extract it anywhere and double-click `omp-webui.exe`: it starts omp-webui and opens the page in your default browser, already signed in. No Bun, Node or terminal is needed.
- Its console window stays open while omp-webui runs; close it to stop omp-webui. Double-clicking again while it runs just opens the page again.
- When port 7878 is taken, it uses the next free port instead of failing.
- If omp isn't installed, the first-run page installs it with omp's PowerShell installer (the standalone `omp.exe`, into `%LOCALAPPDATA%\omp`), or with bun when you have it.
- The program is not signed, so SmartScreen may warn the first time: choose **More info › Run anyway**. There is no automatic update on Windows: download the new zip and replace the folder; your data (`%USERPROFILE%\.omp-webui`) stays.
- Windows still lacks what the macOS app has beyond the page: pause, remote access and the background relay are off there, as before.

## 中文

### Windows 启动器

- 每个发布现在还附带 `omp-webui-vX.Y.Z-windows-x64.zip`（Windows 10 或更高，x64）。解压到任意位置，双击 `omp-webui.exe`：它会启动 omp-webui，并在默认浏览器里打开已经登录的页面。不需要 Bun、Node 或终端。
- 运行期间它的控制台窗口一直开着；关掉这个窗口就停止 omp-webui。运行时再双击一次，只会再打开页面。
- 端口 7878 被占用时，它会改用下一个空闲端口，而不是报错。
- 如果还没有安装 omp，首次运行页面会用 omp 的 PowerShell 安装脚本安装它（独立的 `omp.exe`，装到 `%LOCALAPPDATA%\omp`），装了 bun 时也可以用 bun。
- 程序没有签名，第一次运行时 SmartScreen 可能会警告：点“更多信息 › 仍要运行”。Windows 上没有自动更新：下载新的 zip 替换整个文件夹即可，数据（`%USERPROFILE%\.omp-webui`）会保留。
- Windows 上仍然缺少 macOS 应用在页面之外的功能：暂停、远程访问和后台中继在那里和以前一样是关闭的。
