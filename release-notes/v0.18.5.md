## English

### Plugins page

- **A Plugins page in the sidebar** shows omp's plugins and lets you manage them without a terminal: what is installed (switch each on or off, its features and its settings, a secret's value never shown), what the marketplaces you added offer, install from npm, git or a folder (for you or for a project), uninstall, upgrade when a newer version is out, add, update and remove marketplaces, and omp's plugin doctor with Fix. Each change runs omp's own `omp plugin` command, shows what it prints as it goes, and the open conversations reload their plugins after it (or say they need a restart).
- **Commands & terminal is now in Settings** (Settings › App & system › Open Commands & terminal, or find it with Settings' search); Plugins takes its place in the sidebar. Old `#/cli` links still open it, and a sidebar you arranged keeps Plugins where Commands & terminal was.

### Built-in browser

- **Agents look at pages in the built-in browser**: they are told to open and check web pages there, never in a browser window on your desktop.
- **The Browser tab no longer stays on the previous page**: after a navigation to a page that then did not change, the tab could keep showing the old page's picture under the new page's address and title. A page that has loaded with no picture since it navigated is now drawn again.

### Fixes

- **Live animations no longer stutter**: the caret at the end of a reply being written and the glow of the running time started over each time a new element appeared, which looked like a jump with every update. They now keep one steady beat.
- **Change folder works when the conversation's folder is gone**: the conversation is moved under the folder you pick instead of failing because its old folder no longer exists.
- **A preference changed in one tab is no longer lost** when another tab of the same address loads at the same moment: both tabs went back to the old value and the change was never saved.
- **The conversation list no longer moves down as the page opens**: the search bar's place is kept while it loads, so a click or tap right after opening lands on the row you aimed at.

## 中文

### 插件页

- **侧边栏新增“插件”页**，不用终端也能管理 omp 的插件：查看已安装的插件（逐个开关，设置它的功能和配置项，秘密值从不显示），浏览你添加的市场提供的插件，从 npm、git 或文件夹安装（为你自己或某个项目），卸载，有新版本时升级，添加、更新和移除市场，以及运行 omp 的插件诊断并修复。每项更改都调用 omp 自己的 `omp plugin` 命令，实时显示它的输出，完成后已打开的对话会重新加载插件（或提示需要重启）。
- **“命令与终端”移到了设置里**（设置 › 应用与系统 › 打开命令与终端，也可以用设置的搜索找到），侧边栏中由“插件”代替它的位置。旧的 `#/cli` 链接仍然能打开它，你自定义过的侧边栏会把“插件”放在原来“命令与终端”的位置。

### 内置浏览器

- **智能体在内置浏览器中查看网页**：会被告知在这里打开和检查网页，而不是在你桌面上的浏览器窗口里。
- **浏览器标签页不再停留在上一个页面**：导航到一个之后不再变化的页面时，标签页可能在新页面的地址和标题下继续显示旧页面的画面。现在页面加载后若还没有新画面，会重新绘制。

### 修复

- **实时动画不再卡顿**：正在生成的回复末尾的光标和运行时间的光晕，以前每出现一个新元素就重新开始，看起来每次更新都会跳一下。现在它们保持同一个稳定的节拍。
- **对话所在文件夹已不存在时，“更改文件夹”也能用**：对话会被移到你选的文件夹下，而不是因旧文件夹不存在而失败。
- **在一个标签页里修改的偏好设置不再丢失**：以前同一地址的另一个标签页恰好同时加载时，两个标签页都会回到旧值，修改也不会被保存。
- **页面打开时对话列表不再向下跳**：搜索栏加载期间会保留它的位置，打开后立刻点击或轻点也会落在你想点的那一行上。
