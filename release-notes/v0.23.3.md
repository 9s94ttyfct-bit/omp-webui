## English

### Pick remote computers before a conversation starts

- **New chat has a Remote computers control, right after the guard's.** Once a computer is saved in the Macs list, New chat's settings bar shows **Remote: off**; it opens the same list as Session controls › Remote computers, one tick per computer, with whether this Mac holds its sign-in. Ticked, it reads **Remote: <name>** (or **Remote: <n> computers**) and is highlighted, and the conversation can run commands on those computers (`remote_run`) and copy files to and from them (`remote_copy`) from its first message.
- **Only for the conversation you are starting.** A new project's conversation, started as you send the first message, gets the computers you ticked, even if you send right after ticking. Changing the folder or the options starts over with none, and the next new chat starts with none: remote computers are never on unless you pick them.
- Without a saved computer, nothing changes in the bar. Only your own pages (this Mac's, or one signed in through Cloudflare Access) can tick computers.

## 中文

### 在对话开始前选择远程电脑

- **新对话设置栏多了“远程电脑”，紧挨着 guard。** 在 Mac 列表里保存过电脑后，新对话的设置栏会显示 **远程：关**；点开是和“会话控制 › 远程电脑”同一个列表，每台电脑一个勾，并显示这台 Mac 是否持有它的登录。勾选后显示 **远程：<名称>**（或 **远程：<n> 台电脑**）并高亮，这个对话从第一条消息起就能在这些电脑上运行命令（`remote_run`），并和它们互相复制文件（`remote_copy`）。
- **只作用于正在开始的这个对话。** 新建项目时，发送第一条消息才启动的对话会得到你勾选的电脑，即使勾选后立刻发送也一样。换文件夹或改选项会重新从“关”开始，下一个新对话也从“关”开始：不主动选择就不会接入远程电脑。
- 没有保存过电脑时，设置栏不变。只有你自己的页面（这台 Mac 上的，或通过 Cloudflare Access 登录的）能勾选。
