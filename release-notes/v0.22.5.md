## English

### A page signed in through Cloudflare Access can do everything

- **Your phone or other computer, signed in through Cloudflare Access, now has every permission the page on the Mac has.** It can change Remote access settings, the list of Macs, the guard's log, rules and benchmark, Memory, Move to another computer, Ask agent for help, the projects folder, *Keep the Mac awake* and the unattended instruction, and run the guidance conflict check.
- **Files: everything in the conversation's folder.** Such a page sees, reads, downloads and zips every file, `.env` files, private keys and protected places included; a folder's ZIP no longer leaves them out. It can upload and edit anywhere in the folder (only the app's own data folder stays off limits), whatever *File transfer* is set to, and *Open in default app*, *Reveal in Finder* and *Show in Finder* open them on the Mac.
- **Terminal: a shell is always allowed** on such a page; *Let remote pages open a shell* now only covers pages without an Access sign-in.
- **A ZIP now says exactly what it holds.** Before, the plan could count a file holding a private key that the ZIP then left out; now the plan and the ZIP match.
- **Pages without an Access sign-in are unchanged.** A page on the network, or behind another proxy, that holds only the access token is still kept from secrets, protected places and these settings. *Confirm risky commands from remote pages* still applies to every page that is not on the Mac.

### Host load

- **Network and disks.** The host load pane shows network upload and download speed and the free space of every disk, however many, with a setting for which disks to show.
- **Memory in use on macOS 26** is shown again.

### Forms an agent asks

- **The text around a form's fields** (why it asks, the steps, the command) is now shown with each field, and not on an unrelated approval that comes while the form waits.
- **Unattended conversations** stop a form request and file it as questions, as they do with other questions (omp 18.18.3).

### Windows onto other Macs

- **Notifications**: in a window onto another Mac, the Settings switch now points to the Macs menu, where that Mac's notifications are turned on.

## 中文

### 通过 Cloudflare Access 登录的页面可以做所有事

- **用 Cloudflare Access 登录的手机或其他电脑，现在拥有和这台 Mac 上的页面一样的全部权限。** 可以修改远程访问设置、Mac 列表，查看防护的记录、规则和基准测试，管理记忆、迁移到另一台电脑、“请智能体帮忙”、项目文件夹、“保持 Mac 唤醒”和无人值守说明，也可以运行指引冲突检查。
- **文件：对话文件夹里的一切。** 这样的页面能看到、读取、下载、打包每个文件，包括 `.env`、私钥和受保护的地方；打包文件夹不再漏掉它们。它可以在文件夹里任意位置上传和编辑（只有应用自己的数据文件夹仍然不行），不受“文件传输”设置限制；“用默认应用打开”“在访达中显示”也会在 Mac 上打开。
- **终端：总是可以打开 shell**；“允许远程页面打开 shell”现在只管没有 Access 登录的页面。
- **ZIP 说的就是里面有的。** 以前打包前的计划可能把含私钥的文件算进去，实际 ZIP 却没有；现在两者一致。
- **没有 Access 登录的页面不变。** 只持有访问令牌的网络页面或其他代理后面的页面，仍然拿不到机密、受保护的地方和这些设置。“确认远程页面的危险命令”仍然对所有不在这台 Mac 上的页面生效。

### 主机负载

- **网络和磁盘。** 主机负载面板显示网络上传、下载速度和每块磁盘的剩余空间（不限数量），并可设置显示哪些磁盘。
- **macOS 26 上的已用内存**又能显示了。

### 智能体发来的表单

- **表单字段周围的说明**（为什么问、步骤、命令）现在会和每个字段一起显示，不会出现在表单等待期间到来的无关审批里。
- **无人值守的对话**会拦下表单请求，并像其他问题一样记录成问题（omp 18.18.3）。

### 其他 Mac 的窗口

- **通知**：在其他 Mac 的窗口里，设置中的通知开关现在会指向 Macs 菜单，在那里打开那台 Mac 的通知。
