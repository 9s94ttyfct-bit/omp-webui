## English

### The app icon on the Home Screen and in the Dock

- **A page opened through remote access is saved with omp-webui's icon.** Safari's *Add to Home Screen* (iPhone, iPad) and *Add to Dock* (Mac) fetch the app's icon without the page's cookies, so Cloudflare Access answered that request with its sign-in page and the app was saved with a letter for an icon. The page served through the tunnel now carries its icon inside it, and no separate request is needed. Chrome and Edge already showed the icon. An app saved before this version keeps its letter: remove it and add it again.

### omp 19.0.1 on Linux

- **A conversation that a terminal's omp has open is protected again on Linux.** omp 19.0.1 changed how it marks a conversation as open on Linux, and omp-webui no longer saw that mark when it had a process of its own on the same conversation, so a rename or delete could go ahead under the terminal's omp. Both forms of the mark are recognized now. macOS and Windows were not affected.

## 中文

### 主屏幕和程序坞上的应用图标

- **通过远程访问打开的页面，存为应用时会带上 omp-webui 的图标。** Safari 的“添加到主屏幕”（iPhone、iPad）和“添加到程序坞”（Mac）取应用图标时不带页面的 Cookie，Cloudflare Access 会用它的登录页挡回这个请求，结果应用只显示一个字母当图标。现在通过隧道提供的页面直接把图标放在页面里，不用再单独请求。Chrome 和 Edge 本来就能显示图标。这个版本之前存下的应用仍显示字母：删掉后重新添加即可。

### Linux 上的 omp 19.0.1

- **在 Linux 上，终端里 omp 打开着的对话重新受到保护。** omp 19.0.1 改了在 Linux 上标记“对话已被打开”的方式。omp-webui 自己也有进程打开着同一个对话时，就认不出这个标记，于是改名或删除可能在终端里的 omp 还在用时照样执行。现在新旧两种标记都能识别。macOS 和 Windows 不受影响。
