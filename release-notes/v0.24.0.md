## English

### Keep a project's installs inside its folder

- **New chat has an *Isolated environment* switch** (the package icon in the settings bar). Turn it on for a new project or an existing folder, and what the project's tools install and download goes into the folder's `.ompw-env`: npm (its cache and global installs), bun, pip, uv, cargo, go, Playwright's browsers and Hugging Face downloads. Your own logins (cargo, Hugging Face) keep working. Moving the folder to the Trash removes all of it; the delete dialog lists `.ompw-env` with the folder's other dependencies.
- **It applies to everything in the folder.** The agent, its commands, the Terminal tab and side conversations all get it, and the agent is told what stays inside and to ask before using `brew`, `sudo` or a system package manager. A git worktree of an isolated project gets its own.
- **You can see which conversations have it.** A conversation's header shows **Isolated**, or **Restart to apply** when its folder was switched after it started.
- **It is refused where it would be unsafe**, with the reason: your home folder and the folders above it, system folders, the projects folder itself, and a folder that holds other conversations' folders. It is switched from your own page only, and is not offered on Windows.
- It is not a sandbox: a tool that ignores these settings can still write elsewhere.

## 中文

### 让项目安装的东西留在项目文件夹里

- **新对话里有“独立环境”开关**（设置栏里的包裹图标）。为新项目或已有文件夹打开后，项目的工具安装和下载的东西都会放进文件夹的 `.ompw-env`：npm（缓存和全局安装）、bun、pip、uv、cargo、go、Playwright 的浏览器和 Hugging Face 的下载。你自己的登录（cargo、Hugging Face）照常可用。把文件夹移到废纸篓就全部清掉；删除对话框会把 `.ompw-env` 和文件夹里其他依赖一起列出。
- **对文件夹里的一切都生效。** 代理、它运行的命令、终端标签页和旁问都会用上；代理会被告知哪些会留在项目里，以及使用 `brew`、`sudo` 或系统包管理器前要先问你。独立项目的 git 工作树会有自己的独立环境。
- **能看出哪些对话在用。** 对话的标题栏显示 **独立环境**；对话启动后文件夹的设置被切换过时，显示 **重启后生效**。
- **不安全的位置会拒绝并说明原因**：主目录及其上级、系统文件夹、项目总文件夹本身，以及装着其他对话文件夹的文件夹。只能在你自己的页面上切换；Windows 上不提供。
- 这不是沙箱：不理会这些设置的工具仍可能写到别处。
