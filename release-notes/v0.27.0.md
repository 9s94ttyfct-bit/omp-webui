## English

### omp 19

- **omp 19 is supported.** The range this version is made for is now `>=18.12.3 <20.0.0`, so omp 19.0.0 is no longer announced as untested and updating to it needs no confirmation. It was checked against the unit and contract tests and the end-to-end tests that start a real omp.
- **The built-in browser attaches with omp 19.** omp's own wait for the browser's endpoint sends no sign-in token; the server now answers it, so `browser.open` no longer times out where the web UI's build is not present. The note every agent gets gives both spellings of attaching to another page (`target`, and `app: { target }` before omp 18.19).
- **Windows: conversations are listed where omp writes them.** omp follows `XDG_DATA_HOME` and `XDG_STATE_HOME` on Linux and macOS only; on Windows the server no longer looks for conversations, memories and usage figures there.
- omp 19's `local://N.log` links (formerly `artifact://N`) are shown as text, like every address only omp can open.

### Security

- **A page that holds only the access token can no longer act as you.** It cannot reach the owner-only settings through a command it runs, answer the guard's questions, set the default permission mode, install plugins, run shells or slash commands (`/mcp add`, `/export`) while shells are off, start a conversation inside `.git`, `.github` or a hidden folder to get past the Files tab's rules, move folders to the Trash, or overwrite a file that holds a private key (#189, #190, #209, #213, #219, #220, #226, #228, #346, #349, #368).
- The Feedback dialog no longer puts the computer's name, its addresses or the tunnel's hostname into the issue (#247). On Linux the sign-in token is no longer on the browser's command line (#287). The macOS updater refuses an ad-hoc-signed download (#276). Remote access stops trusting a withdrawn Cloudflare Access key (#373), and a page signed in through Access cannot save settings that lock itself out (#363).

### The guard

- **Many more risky commands are asked about**: commands hidden behind wrappers (`arch`, `sandbox-exec`, `flock`, `busybox`, `taskpolicy`, `systemd-run`, `unshare`, debuggers…), downloaded scripts run by any interpreter or through process substitution and here-strings, publishing (`npm publish`, `gh release create`…), destructive cloud and repository commands (`gh repo delete`, `terraform destroy`, `rm -rf .git`, `git worktree remove --force`…), deletes by archivers and by other languages' file APIs, macOS's `trash`, Gatekeeper and privacy resets, bind shells, LaunchAgents, `kill -9 -1`, `sudoedit`, and global installs of every package manager (#191, #192, #216–#218, #221–#224, #227, #250–#265, #274, #275, #281–#283, #291, #293, #315, #316, #318, #320, #322, #412–#424).
- Reading credentials is recognised in many more places (provider keys in the environment, browser cookies and saved passwords, omp's own tokens), and case-insensitive checks fold names as APFS does (#250, #260, #291, #293, #320, #352).
- The reviewer's failures are shorter and clearer: a failing provider no longer holds every call for 30 s, no log path reaches the dialog, and a closed question still leaves a decision in the log (#403, #406, #408, #411).

### Conversations

- A conversation whose subagent still works is busy and cannot be deleted (#194). Stop's withdrawn messages, slash commands in flight and messages held behind a compact are no longer lost (#198, #199, #398).
- Unattended mode files questions written through `eval` and `xd://`, keeps every open question, can be answered after a conversation moved, and handles a reviewer that cannot be reached (#233, #234, #309, #384, #385, #393, #405).
- A permission mode chosen while paused is in force after Resume (#407); session settings no longer flip back after a change (#386). Two pages sending at once, a `!command`, and omp dying mid-turn are all shown correctly (#389, #394, #397).
- Deleting a conversation warns about unpushed work on any branch and never offers to trash a home folder, `~/Documents` or Homebrew (#235, #236, #355, #356).
- **Editing a prompt shows ‹ 1/2 › again with omp 18.22 and later.** omp now writes a hidden reminder before every prompt, so an edited prompt no longer sat beside the one it replaced and its versions could not be switched; those entries are now passed over.

### Files, uploads and downloads

- Uploads: no more lost or duplicated files (#241, #348), long and Unicode names work (#317, #340, #341), a crash leaves no hidden file behind (#350), closing the page asks first (#353), and the composer's upload keeps a disk reserve (#343).
- The editor keeps Finder tags and CR line endings (#300, #351); GBK, Latin-1 and UTF-16 files open as text (#284); a folder's ZIP leaves out what `.gitignore` names (#347).

### Search, settings and the page

- Search folds accents correctly for every word length and script, ranks short words, and reaches every match in a conversation (#229, #279, #354, #357, #400).
- Settings that fail to load say so and can be tried again (#267, #270, #271, #328); changes made in another window show up (#239, #329, #331).
- Accessibility: the Terminal is readable by screen readers and gives the keyboard back, wide tables scroll from the keyboard, focus is kept after restarts (#266, #268, #277, #289). Phones can send Esc/Tab/Ctrl-C in the Terminal and type a new line in the composer (#369, #370).
- Repeated identical toasts merge into one with a count (#382). Numbers, dates and plural forms follow the language chosen in Settings (#201, #232, #409, #410). Older Safari (iOS 16.4–17.3) works again (#269), and a page left open across an update says that a new version is there and offers to reload (#273).

### Remote access, macOS, Windows and Linux

- `remote_run` and `remote_copy` work with fish shells and servers without sign-in, keep nothing in shell history, and stay fast with large output (#243, #364, #365, #371, #416).
- macOS app: menus and alerts follow the app's language, quitting with remote access connected shuts down cleanly, pop-outs follow a server that moved, and a typed draft survives closing the window (#232, #374, #376–#380, #399).
- Windows: npm- and bun-installed omp are recognised and updated, `OMP_BIN` with forward slashes works, and arguments with special characters reach omp intact (#288, #294, #296). Linux: uninstalling removes the login item, and `BROWSER` lists work (#292, #297).

## 中文

### omp 19

- **支持 omp 19。** 这个版本适用的 omp 范围改为 `>=18.12.3 <20.0.0`，omp 19.0.0 不再被标为未经测试，更新到它也不再需要确认。它跑过了单元测试、契约测试和启动真实 omp 的端到端测试。
- **内置浏览器在 omp 19 下能正常连接。** omp 等待浏览器端点时不带登录令牌；服务器现在会回应它，所以在没有网页界面构建产物的环境里，`browser.open` 也不会再超时。给每个智能体的说明同时写了连接另一个页面的两种写法（`target`，以及 omp 18.19 之前的 `app: { target }`）。
- **Windows：对话在 omp 实际写入的位置列出。** omp 只在 Linux 和 macOS 上遵循 `XDG_DATA_HOME` 和 `XDG_STATE_HOME`；在 Windows 上，服务器不再去那里找对话、记忆和用量数据。
- omp 19 的 `local://N.log` 链接（以前是 `artifact://N`）和其他只有 omp 能打开的地址一样，以文本显示。

### 安全

- **只持有访问令牌的页面不能再冒充你。** 它不能通过自己运行的命令访问仅限本人的设置，不能回答守卫的问题、设置默认权限模式、安装插件，在关闭 shell 时也不能运行 shell 或斜杠命令（`/mcp add`、`/export`），不能在 `.git`、`.github` 或隐藏文件夹里开对话来绕过文件标签页的规则，不能把文件夹移到废纸篓，也不能覆盖存有私钥的文件（#189、#190、#209、#213、#219、#220、#226、#228、#346、#349、#368）。
- “反馈”对话框不再把电脑名、地址或隧道主机名写进 issue（#247）。Linux 上登录令牌不再出现在浏览器的命令行里（#287）。macOS 更新器拒绝临时签名的下载（#276）。远程访问不再信任已撤回的 Cloudflare Access 密钥（#373），通过 Access 登录的页面也不能保存会把自己锁在外面的设置（#363）。

### 守卫

- **更多有风险的命令会先询问**：藏在包装命令后面的命令（`arch`、`sandbox-exec`、`flock`、`busybox`、`taskpolicy`、`systemd-run`、`unshare`、调试器等），由任何解释器或通过进程替换、here-string 运行的下载脚本，发布（`npm publish`、`gh release create` 等），破坏性的云端和仓库命令（`gh repo delete`、`terraform destroy`、`rm -rf .git`、`git worktree remove --force` 等），归档工具和其他语言文件接口造成的删除，macOS 的 `trash`、Gatekeeper 与隐私权限重置，绑定 shell、LaunchAgent、`kill -9 -1`、`sudoedit`，以及各种包管理器的全局安装（#191、#192、#216–#218、#221–#224、#227、#250–#265、#274、#275、#281–#283、#291、#293、#315、#316、#318、#320、#322、#412–#424）。
- 能识别更多读取凭据的方式（环境变量里的服务商密钥、浏览器 Cookie 和保存的密码、omp 自己的令牌），不区分大小写的检查也按 APFS 的方式折叠文件名（#250、#260、#291、#293、#320、#352）。
- 审查模型出错时更简短清楚：服务商出错不再让每个调用都卡 30 秒，日志路径不会出现在对话框里，问题被关闭时日志里仍留有决定（#403、#406、#408、#411）。

### 对话

- 子智能体还在工作的对话算作忙碌，不能删除（#194）。“停止”撤回的消息、正在发送的斜杠命令、排在压缩后面的消息都不再丢失（#198、#199、#398）。
- 无人值守模式会记下通过 `eval` 和 `xd://` 提出的问题，保留所有未回答的问题，对话移动后仍能回答，审查模型连不上时也能正确处理（#233、#234、#309、#384、#385、#393、#405）。
- 暂停时选择的权限模式在恢复后生效（#407）；对话设置改动后不再弹回原值（#386）。两个页面同时发送、`!命令`、omp 在一轮中途退出，现在都能正确显示（#389、#394、#397）。
- 删除对话时，任何分支上有未推送的提交都会提醒，也不会再提议把主文件夹、`~/Documents` 或 Homebrew 移到废纸篓（#235、#236、#355、#356）。
- **在 omp 18.22 及以上版本中，编辑提示后又能看到 ‹ 1/2 ›。** omp 现在会在每个提示前写一条隐藏的提醒，所以编辑后的提示不再和被替换的那条并列，版本也就切换不了；现在会跳过这些条目。

### 文件、上传和下载

- 上传：不再丢文件或重复（#241、#348），长文件名和各种 Unicode 文件名都能用（#317、#340、#341），崩溃后不会留下隐藏文件（#350），关闭页面前会先询问（#353），对话框里的上传也会保留磁盘余量（#343）。
- 编辑器保留 Finder 标签和 CR 换行（#300、#351）；GBK、Latin-1 和 UTF-16 文件以文本打开（#284）；文件夹打包 ZIP 时不包含 `.gitignore` 列出的内容（#347）。

### 搜索、设置和页面

- 搜索对任何长度、任何文字的词都能正确忽略重音，会给短词排序，并能找到对话里的每一处匹配（#229、#279、#354、#357、#400）。
- 读取失败的设置会说明并可以重试（#267、#270、#271、#328）；在另一个窗口里的改动会显示出来（#239、#329、#331）。
- 无障碍：终端能被读屏软件读出，也会把键盘交还出来；宽表格能用键盘滚动；重启后焦点不丢（#266、#268、#277、#289）。手机上能在终端发送 Esc/Tab/Ctrl-C，也能在输入框里换行（#369、#370）。
- 相同的提示会合并成一条并显示次数（#382）。数字、日期和复数形式跟随设置里选择的语言（#201、#232、#409、#410）。较旧的 Safari（iOS 16.4–17.3）又能用了（#269），更新时一直开着的页面会提示有新版本并可重新加载（#273）。

### 远程访问、macOS、Windows 和 Linux

- `remote_run` 和 `remote_copy` 支持 fish shell 和不需要登录的服务器，不会在 shell 历史里留下任何东西，输出很大时也不会变慢（#243、#364、#365、#371、#416）。
- macOS 应用：菜单和提示跟随应用的语言，连着远程访问时退出也能干净地关闭，服务器换端口后弹出窗口会跟上，关闭窗口时刚输入的草稿不会丢（#232、#374、#376–#380、#399）。
- Windows：能识别并更新用 npm 和 bun 安装的 omp，带正斜杠的 `OMP_BIN` 可用，带特殊字符的参数能原样传给 omp（#288、#294、#296）。Linux：卸载时会移除登录启动项，`BROWSER` 列表也能用（#292、#297）。
