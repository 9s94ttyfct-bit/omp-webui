## English

### Host load

- **The sidebar's line shows the power draw too**: `CPU 12% · GPU 3% · MEM 61% · 6.2 W`, the whole Mac's draw from the SMC, as the pane's *Power* tile has it. A screen reader hears *power 6.2 W*. A computer that tells no power draw shows no watts. In a narrow sidebar the line now breaks between two figures instead of cutting off the last one.

### Conversations

- **The folder under a conversation's title changes its folder**, as the folder on the status line does: a click opens the folder picker on it (its tooltip says *Change folder…*). Not while a turn runs.

## 中文

### 本机负载

- **侧边栏那一行也显示功耗**：`CPU 12% · GPU 3% · 内存 61% · 6.2 W`，即整台 Mac 的功耗，来自 SMC，和面板里的“整机功耗”数值块相同。读屏软件读作“功耗 6.2 W”。电脑不提供功耗时不显示瓦数。侧边栏较窄时，这一行在两个数值之间换行，而不是把最后一个截掉。

### 对话

- **点对话标题下方的文件夹即可更改文件夹**，和点状态栏上的文件夹一样：会在它当前的文件夹打开文件夹选择器（悬停提示写着“更改文件夹…”）。对话正在回复时不可用。
