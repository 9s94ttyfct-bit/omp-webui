## English

### Five colour palettes (#182)

- Settings › Appearance now offers five palettes — Claude (the familiar look), ChatGPT, Terminal, OMP and Hermes — each with a light and a dark version. The palette is chosen separately from Light / Dark / System and applied before the first paint, so nothing flashes. Code highlighting follows the palette, and the browser's own chrome colour matches the page.

### Polished details (#181)

- Scrollbars, range sliders, resize handles, focus rings, text selection and the caret share one refined style in every palette. A few colours of the Claude palette were nudged so every palette meets WCAG AA contrast.

## 中文

### 五套配色（#182）

- “设置 › 外观”新增五套配色：Claude（原来的样子）、ChatGPT、终端、OMP 和 Hermes，每套都有浅色和深色。配色与“浅色 / 深色 / 跟随系统”分开选择，并在页面首次绘制前生效，不会闪烁。代码高亮颜色随配色变化，浏览器外框颜色与页面背景一致。

### 细节打磨（#181）

- 滚动条、滑块、拖动条、焦点环、文字选中和光标在每套配色下都统一为同一套精致样式。Claude 配色里的少数颜色做了细微调整，使每套配色都达到 WCAG AA 对比度。
